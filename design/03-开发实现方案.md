# 03 开发实现方案（Popup Viewer V2）

> 对应版本：v2.0.5 · 工程视角实现细节。
> 架构背景见《02 架构方案》，需求见《01 需求功能设计》。

## 1. 目录结构与构建

```
├── src/
│   ├── main.js              # 入口：初始化装配
│   ├── config.js            # 全局配置
│   ├── core/                # 核心层（7 模块）
│   ├── ui/                  # 界面层（7 模块）
│   ├── loaders/             # 加载层（4 加载器 + 1 渲染器）
│   ├── adapters/            # 站点适配层（5 文件）
│   ├── security/            # 安全层（3 模块）
│   ├── kit/                 # PopupKit 独立库（2 文件）
│   └── utils/               # 工具层（5 文件）
├── build.mjs                # esbuild 构建脚本
├── banner.txt               # 用户脚本头（@version/@grant/@match 等）
├── package.json
├── README.md · CHANGELOG.md · AGENTS.md
├── design/                  # 本文档系列（需求/架构/实现）
└── dist/                    # 构建产物（popup-viewer-v2.user.js + popup-viewer-kit.js）
```

**构建**：`npm run build` → esbuild 打包 `main.js` 为主脚本、`kit/popupKit.js` 为库；CSS 以文本内联；banner 合并进产物头部。`npm run dev` 监听模式。

**版本同步约束（AGENTS.md）**：涉及代码更新的提交前先递增 `package.json` + `banner.txt` 的版本号，随后重新构建 `dist/` 同步；纯文档/配置类改动无需递增。

## 2. 模块实现细节

### 2.1 main.js（入口装配）

```
init():
  settingsManager.load()                       // 1. 加载设置
  if (isInIframe() && !allowInFrame) return     // 2. iframe 内默认跳过
  popupManager.popup.applyTheme(settings.theme)
  popupManager.popup.ensure()                   // 3. 立即构建 UI（含设置按钮）
  registerAdapters()                            // 4. 注册 4 个内置适配器
  applyForumMarker()                            // 5. Discuz 站点加 .pv-forum 标记
  setupEvents()                                 // 6. click/mouseover/事件总线
  setupObserver()                               // 7. MutationObserver + debounce 增强
```

要点：
- **click 用 capture 阶段**（`document.addEventListener('click', handler, true)`），保证在站点脚本之前拦截。
- **mouseover 预热**复用 `SiteManager.resolveCandidate`，不修改事件。
- **`eventBus.on('open-page')`** 统一入口：写历史 + 打开弹窗。
- **`settings-changed`** 事件：切换 `windowMode` 时联动遮罩显隐。
- **MutationObserver** 防抖（300ms，leading）触发 `runEnhancements`，应对动态加载的列表。

### 2.2 config.js

- `popup.sizes`：small/medium/large/phone 四档尺寸；`phone.sizes`：iPhone/Max/安卓/小屏，各带移动端 UA。
- `loader.defaultMode: 'auto'`：不强制，走 cache（见 2.4 决策）。
- `cache`: TTL 30min、maxEntries 50、enabled true。
- `sitePolicy`: 三个白名单站点（`iframe`/`scripts` 标记），unknown 兜底。
- `storage` 键与 `maxHistoryEntries: 100`。

### 2.3 SiteManager / RulesManager

**SiteManager.resolveCandidate(event)** 顺序：
1. `event.target.closest('#popup-content-panel')` → 自身 UI 不拦截。
2. 用户规则优先：`rulesManager.match` → URL 校验。
3. 遍历 `activeAdapters(hostname,pathname)` → `parseClick` → URL 校验。
4. 任一步骤 URL 不合法（危险协议/同页锚点）即返回 null。

**handleClick**：命中则 `preventDefault + stopPropagation`，`eventBus.emit('open-page')`，返回 true。

**RulesManager.match**：对每条规则用 `event.target.closest(selector)`（try/catch），命中后 `_extractLink` 提取：`a[href]` → `data-topic-url`/`data-href` → 内部/最近 `a[href]`。

### 2.4 LoaderManager / 加载器

**resolveMode**（见架构文档 §4）。当前配置下非白名单站点实际走 **cache（≈request）** 路径。

**IframeLoader.load**：
- 构建 sandbox iframe（`buildSandboxAttrs(hostname)`），`width/height 100%`。
- 15s 超时 → onError 提示新标签页兜底。
- 返回 abort：清 timer、`src='about:blank'`、移除 iframe。

**RequestLoader.load**：
- `gm.xmlhttpRequest` GET，可带移动端 UA。
- 200 校验 → `sanitizer.sanitize` → `renderIntoIframe`。
- 返回 abort：`req.abort()` + 移除 iframe。

**CacheLoader**：
- `_readCache` 检查 TTL 过期；`_writeCache` 淘汰最旧（Map 迭代首项）。
- `prefetch` 用 `inflight` Map 对同一 URL 去重。
- `load`：缓存命中直接渲染；否则 `prefetch().then` 渲染。

**ParserLoader.load**：
- 抓取净化 → 用 `DOMParser` 解析 body → `_absolutize` 绝对化链接/图片 → `clear(container)` 后整体移入弹窗容器（不套 iframe）。
- 链接拦截开关控制 `target='_blank'`；图片统一 `loading='lazy'`。

### 2.5 IframeRenderer（渲染器）

```
renderIntoIframe({html, head, url, container, sandboxAttrs, linkIntercept, loadingSelector}):
  iframe 注入 → iframeDoc.open/write(buildDocument)/close
  runFixes(): fixLinks → injectReadStyle → fixImages
  触发：iframe load 事件 + 1500ms + 3500ms 兜底
```

- **buildDocument**：`<base href>`（无扩展名路径补 `/`，避免相对图片拼错父级）+ 注入 head 样式。
- **fixLinks**：绝对化所有 `a[href]`；拦截开关决定 `_blank`。
- **injectReadStyle**：阅读兜底样式（`body` 字体/断行、`img/video/iframe max-width:100%`、链接配色），插到 head 首位，保证可被站点样式覆盖。
- **fixImages**：每图 `loading='eager'`；src 为空/占位图名/naturalWidth=0 时从 `IMG_REAL_ATTRS`（含 `zoomfile`/`file`/`data-*`）换真实地址；处理 `data-srcset`；最后对仍失败的图重设 src 重试一轮。

### 2.6 Sanitizer（净化器）

```
sanitize(html, baseUrl, {keepScripts}):
  DOMParser 解析 → _collectHead(样式，绝对化) → _purge(标签/属性) → _resolveLazyImages
```

- **removedTags**：script/iframe/frame/frameset/object/embed/applet/form/link/meta/base/noscript；`keepScripts` 时豁免 script。
- **_sanitizeAttrs**：删 `on*`；删 `srcdoc`；`href` 拦 javascript/data/vbscript/file 协议；`src`/`poster` 拦 javascript/vbscript/file（data: 图片放行）。
- **_resolveLazyImages**：遍历 `REAL_SRC_ATTRS`（16 个 data 属性 + Discuz `zoomfile`/`file`），取第一个非空 → 绝对化 → 写回 src → 清理属性/`lazy` class → `loading='lazy'`；否则尝试 `data-srcset`。
- **_collectHead**：收集 `link[rel=stylesheet]`、`.css`、`preload as=style`、`head style`，去重并绝对化（样式可能出现在 body，如淘股吧）。

### 2.7 Sandbox / UrlResolver

- **Sandbox.policyFor**：精确匹配 → 子域名后缀匹配 → unknown 兜底。`buildSandboxAttrs`：基础权限 + `scripts` 时补 `allow-same-origin allow-scripts`。
- **UrlResolver**：`resolve` 绝对化、`isHttpUrl`、`isDangerous`（协议前缀匹配）、`isSamePageAnchor`（同源同 path 且带 hash）。

### 2.8 PopupPanel（主弹窗）

- **ensure()** 一次性构建：遮罩 → 头部（标题+工具栏）→ 内容区 → 底部 URL；追加右下角悬浮设置齿轮、设置面板、规则面板（backdrop+root）。
- **show(title,url)**：保留拖动位置；全屏时恢复全屏前位置；`applySettings` 套用尺寸/滚动条/主题。
- **applySettings**：尺寸预设 → CSS 变量 `--popup-width/height`；手机模式 → 套手机 UA 尺寸 + `restorePhonePosition`；退出手机模式 → `savePhonePosition` + 居中。
- **拖拽**：header mousedown → document mousemove/mouseup；up 时 `_clampToViewport`（视口 8px 边距约束）+ 手机模式存位置。
- **快捷键**：Esc/F/R；R 排除 ctrl/meta/alt。**滚动链兜底**：wheel 捕获阶段，全屏时全拦截；否则内容滚到底或不可滚时 preventDefault。
- **全屏**：记录 `preFullScreen` 快照，切换 100vw/100vh + zIndex 10002，恢复时回写。
- **内容区点击**（linkIntercept===false）：找 `a[href]` 非 javascript/# → `onOpenInWindow` 窗内加载。

### 2.9 SettingsPanel / RulesPanel / ElementPicker

- **SettingsPanel**：`makeSeg` 分段控件工厂（同步 active/is-default）；开关（滚动条/拦截/iframe）；tooltip 说明；「恢复默认」重置后同步所有控件；`persist()` = onChange + `eventBus.emit('settings-changed')`。站点子控件（手机型号）仅 panelSize=phone 时显示。
- **RulesPanel**：列表渲染（选择器 + 本页匹配数）；删除需二次点击确认（2.2s 过期）；`startPick` 收起面板 → `pickElement()` → 恢复 → `addRule`。
- **ElementPicker**：全文档 capture 监听（mousemove/mouseover/click/touchend/scroll/resize/keydown）；遮罩/提示条 `pointer-events:none`；`elementsFromPoint` 取最上层非自属元素；`buildSelectorCandidates` 生成候选 → 确认面板（候选按钮/可编辑输入/实时匹配数）。完成即 `cleanup` 移除监听与 DOM。

### 2.10 KitPopupPanel / popupKit（PopupKit 库）

- 与主弹窗 **功能平行但独立**：`pvk-` 前缀、内联 loading/error、不依赖 SettingsManager/主脚本 UI。
- `panel.setHandlers({onOpen, onClose, onRefresh})`；`open(opts)` 首开居中、后续保留拖拽位；拖拽/全屏/视口约束/滚动链逻辑与主弹窗一致（独立实现）。
- `popupKit.js` 组装 LoaderManager + KitPopupPanel，`window.PopupKit` 暴露 API 与 `_onOpen/_onClose` 回调。通过 `opts.linkIntercept`、`loadingSelector` 注入行为。

### 2.11 utils/（工具实现要点）

- **gm**：`addStyle`/`xmlhttpRequest`/`getValue`/`setValue` 四接口，有 `GM_*` 用之（try/catch），否则分别降级 `injectStyle`/`fetch`(Promise 包装 onload/onerror)/`localStorage`（键前缀 `popup-viewer:`，JSON）。
- **dom**：`el` 支持 class/text/style对象/on*事件/子节点；`svgIcon` 内置图标路径字典；`clear` 清空节点。
- **selector**：`isStableClassName` 排除工具类（is-/has-/js-、框架哈希类、纯 hex）；`buildSelectorCandidates` 生成 id/class/父级范围/nth-child 路径，按「2~200 匹配数优先」排序，最多 8 个。
- **logger**：统一 `[PopupViewer]` 前缀；debug 仅 `?pv2_debug` 时输出。

## 3. 关键流程时序

### 3.1 打开弹窗（抓取净化路径，默认 cache）

```
用户点击 a.xst
  → SiteManager.resolveCandidate → {url,title,element}
  → PopupManager.open
  → popup.show(title,url)              [面板 visible]
  → LoaderManager.load(url, {hostname})
  → resolveMode → 'cache' → CacheLoader.load
  → prefetch (未缓存) → gm.xhr GET
  → 200 → sanitizer.sanitize(html,url)
  → CacheLoader._writeCache (内存)
  → renderIntoIframe
  → iframe load → fixLinks/injectReadStyle/fixImages
  → +1500ms/+3500ms fixImages 兜底
```

### 3.2 悬停预热

```
mouseover → resolveCandidate
  → PrefetchManager.schedule(url,host)
  → resolveMode==='cache' && !hasCached && url 不同
  → 防抖 150ms → prefetch（GET+净化+写缓存，inflight 去重）
点击时 → CacheLoader.load 命中 → 立即渲染
```

### 3.3 取选器确认

```
点「取选新链接」 → RulesPanel.startPick
  → 隐藏面板 → pickElement()
  → hover 高亮（elementsFromPoint + pointer-events:none）
  → click → buildSelectorCandidates → 候选列表
  → 选候选/改输入 → updateMeta 实时匹配数 → 确认
  → 恢复面板 → rulesManager.addRule(host, sel) → renderList → toast
```

## 4. GM API 与降级对照

| 用途 | GM API | 降级 |
|---|---|---|
| 注入样式 | `GM_addStyle` | `document.head` 追加 `<style>` |
| 网络请求 | `GM_xmlhttpRequest` | `fetch`（Promise 包装 onload/onerror，含状态/文本/finalUrl） |
| 读写存储 | `GM_getValue`/`GM_setValue` | `localStorage`（键前缀 `popup-viewer:`，JSON 序列化） |

> `GM_xmlhttpRequest` 跨域需 banner `@connect *`；降级 fetch 受同源/CORS 限制，体验以 GM 环境为准。

## 5. 发布流程

1. 改代码 → `npm run build`（产出 `dist/popup-viewer-v2.user.js` + `popup-viewer-kit.js`）。
2. 涉及代码更新 → 先递增 `package.json` + `banner.txt` 版本号再构建，保证 dist 头一致。
3. 更新 `CHANGELOG.md`。
4. 提交 + 推送（可用 `npm run g -- publish "信息"` 一键构建+提交+推送；纯文档改动无需递增版本）。

## 6. 已知问题与踩坑

| 项 | 说明 |
|---|---|
| Discuz 图片占位 | v2.0.5 前 52pojie/wnflb 附件图 `src=none.gif`（naturalWidth=1）绕过判定不显示；已通过 `zoomfile`/`file` 识别 + 占位图文件名判定修复 |
| 淘股吧正文图 | `src=placeHolder.png` + `data-original`(760w) + `src2`(max)；通用净化只取 `data-original`，`onclick` 看大图交互被净化剥离，弹窗内无法点放大 |
| 样式污染 | 依赖 `popup-`/`pv-`/`pvk-` 前缀 + `@layer` 隔离 + 内联 `pointer-events:none`；仍可能被极端宿主 CSS 干扰 |
| iframe 内运行 | 开启后所有 iframe 初始化，可能多悬浮按钮/样式冲突/开销上升 |
| 直接 iframe 无法设 UA | IframeLoader 对移动端 UA 仅记日志，手机模式对直载站点不生效 |
| 缓存非持久 | 内容缓存仅内存，刷新页面失效 |
| 站点 DOM 变化 | 依赖 MutationObserver 防抖重扫；选择器命中依赖站点 class 稳定性 |

## 7. 测试与调试
