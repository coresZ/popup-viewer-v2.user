# 02 架构方案（Popup Viewer V2）

> 对应版本：v2.0.5 · 描述现状架构。
> 需求背景见《01 需求功能设计》，实现细节见《03 开发实现方案》。

## 1. 架构总览

系统按职责分为六层，外加独立发布的 PopupKit 库。模块间通过显式接口（构造函数注入 / 事件总线 / 单例）通信，无循环依赖。

```
┌─────────────────────────────────────────────────────────────┐
│                         入口 main.js                         │
│   初始化顺序：设置加载 → iframe 检查 → UI 构建 → 适配器注册    │
│             → 论坛标记 → 事件监听 → MutationObserver         │
└──────────┬──────────────────────────────────────────────────┘
           │
┌──────────▼──────────────────────────────────────────────────┐
│                        core/ 核心层                         │
│  SiteManager  站点解析/增强分发     LoaderManager 加载器调度  │
│  PopupManager 弹窗生命周期         PrefetchManager 悬停预热  │
│  SettingsManager 设置(全局/站点)   StorageManager 历史/收藏  │
│  RulesManager  链接规则管理         EventBus 事件总线        │
└──────┬───────────────┬─────────────────────────┬────────────┘
       │               │                         │
┌──────▼───┐   ┌───────▼────────┐   ┌────────────▼──────────┐
│ adapters/│   │   loaders/     │   │       ui/             │
│ 站点适配器│   │  iframe/request│   │  PopupPanel 主弹窗    │
│ BaseAdapter│  │  parser/cache │   │  SettingsPanel 设置   │
│ Discuz/Tgb│   │  IframeRenderer│   │  RulesPanel 规则面板  │
│ Linux/Cili│   │  渲染器        │   │  ElementPicker 取选器 │
└───────────┘   └──────┬────────┘   │  Toolbar/Loading/Error│
                       │             └──────────┬───────────┘
              ┌────────▼──────────┐              │
              │   security/       │     ┌────────▼───────────┐
              │  Sanitizer 净化   │     │     utils/          │
              │  UrlResolver 校验 │     │  gm(API降级)/dom/   │
              │  Sandbox 沙箱     │     │  selector/debounce/ │
              │                   │     │  logger             │
              └───────────────────┘     └────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│                    kit/ PopupKit（独立库，单独打包）            │
│  popupKit.js 暴露 window.PopupKit · KitPopupPanel 精简面板     │
│  复用 loaders + security + utils + config，不依赖主脚本 UI    │
└──────────────────────────────────────────────────────────────┘
```

**依赖方向**：`ui` 依赖 `core`/`security`/`utils`；`core` 依赖 `loaders`/`security`/`utils`；`loaders` 依赖 `security`/`utils`；`adapters` 只依赖 `utils`。所有层共用 `config.js` 与 `logger`。

## 2. 模块职责

### 2.1 config.js（全局配置）

单一配置源：弹窗尺寸预设、手机模式预置与 UA、加载器超时/默认模式、缓存 TTL/上限、预热防抖、站点加载策略（`sitePolicy`）、存储键、历史上限。

### 2.2 core/

| 模块 | 职责 | 关键接口 |
|---|---|---|
| `SiteManager` | 适配器注册表；把事件解析为可打开的候选；分发点击与增强 | `register` `resolveCandidate` `handleClick` `runEnhancements` `registerEnhancer` |
| `LoaderManager` | 按站点策略解析加载方式并分派给具体加载器；持有沙箱 | `resolveMode` `load` `prefetch` `hasCached` `_keepScripts` `_mobileUA` |
| `PopupManager` | 弹窗生命周期：打开/加载/关闭；衔接 PopupPanel 与 LoaderManager | `open` `load` `close` `hideOverlay` `showOverlay` |
| `PrefetchManager` | 悬停预热：防抖调度、并发去重、中止当前请求 | `schedule` `cancel` `abort` |
| `SettingsManager` | 全局+站点设置读写、默认值、不变式（拦截关闭→强制悬浮） | `load` `get` `set` `reset` |
| `StorageManager` | 历史/收藏读写（JSON 序列化，去重 + 上限） | `addHistory` `addFavorite` `removeFavorite` 等 |
| `RulesManager` | 按站点存取链接规则（选择器列表） | `getRules` `addRule` `removeRule` `match` |
| `EventBus` | 轻量事件总线（on/once/off/emit/clear） | — |

### 2.3 adapters/（站点适配层）

| 模块 | 职责 |
|---|---|
| `BaseAdapter` | 接口基类：`match(hostname,pathname)` / `parseClick(event)` / `enhance(doc)` / `resolveHref` |
| `DiscuzAdapter` | Discuz! 论坛：`a.xst` 标题链接、`td.suh` 回复区；论坛标记 `forumStyles` |
| `TgbAdapter` | 淘股吧：板块列表（新旧布局）、博客、实盘比赛、快讯；`data-topic-url` 可点块 |
| `LinuxAdapter` | linux.do：Discourse 主题标题链接 |
| `CiliAdapter` | 磁力站：列表行首格链接 |

### 2.4 loaders/（加载层）

| 模块 | 职责 |
|---|---|
| `IframeLoader` | 直接 iframe 加载（白名单站点保留脚本/登录态），超时兜底 |
| `RequestLoader` | `GM_xmlhttpRequest` 抓取 → 净化 → 渲染进沙箱 iframe |
| `ParserLoader` | 抓取净化 → 直接 DOM 解析渲染进弹窗容器（不套 iframe） |
| `CacheLoader` | 抓取净化 → 内存缓存（TTL 30min / 50 条）；并发去重；命中直接渲染 |
| `IframeRenderer` | 把净化后 HTML 注入 iframe：`<base>` 绝对化、链接改写、注入阅读样式、图片恢复兜底 |

### 2.5 security/（安全层）

| 模块 | 职责 |
|---|---|
| `Sanitizer` | 剥离脚本/iframe/表单等危险标签；清理 `on*` 事件；拦截危险协议；解析懒加载图片 |
| `UrlResolver` | URL 解析与合法性判断（http(s)、同页锚点、危险协议） |
| `Sandbox` | 站点策略查询（含子域名匹配）；生成 iframe sandbox 属性 |

### 2.6 ui/（界面层）

| 模块 | 职责 |
|---|---|
| `PopupPanel` | 主弹窗：拖拽/全屏/快捷键/设置/规则/底部 URL/视口自适应/滚动链 |
| `Toolbar` | 弹窗头部工具栏按钮 |
| `SettingsPanel` | 设置面板：分段控件/开关/tooltip/恢复默认 |
| `RulesPanel` | 链接规则面板：列表/删除/取选入口 |
| `ElementPicker` | 取选模式：悬停高亮→候选选择器→确认 |
| `Loading` / `ErrorView` | 加载中 / 加载失败视图 |

### 2.7 utils/（工具层）

| 模块 | 职责 |
|---|---|
| `gm` | `GM_*` API 封装，无 GM 时降级（addStyle→injectStyle；xhr→fetch；get/setValue→localStorage） |
| `dom` | DOM 构建辅助：`el`/`svg`/`svgIcon`/`clear`；内置 SVG 图标路径 |
| `selector` | CSS 选择器候选生成：稳定 class/id 判断、nth-child 路径、按匹配数排序 |
| `debounce` | 防抖（支持 leading） |
| `logger` | 带前缀日志；`?pv2_debug` 开启 debug 级别 |

### 2.8 kit/（PopupKit 独立库）

| 模块 | 职责 |
|---|---|
| `popupKit.js` | 组装 LoaderManager + KitPopupPanel，暴露 `window.PopupKit`（open/close/refresh/isOpen/prefetch/hasCached/config/回调） |
| `KitPopupPanel` | 精简弹窗面板（拖拽/全屏/刷新/新标签页/关闭/快捷键），`pvk-` 前缀，内联 loading/error，不依赖主脚本 UI |

## 3. 核心数据流

### 3.1 点击→打开→加载→渲染

```
click 事件（capture）
  └─ SiteManager.resolveCandidate(event)
       ├─ rulesManager.match(event, hostname)      // 用户规则优先
       └─ activeAdapters → adapter.parseClick(event)
       └─ UrlResolver 校验（isHttpUrl / isDangerous / isSamePageAnchor）
  └─ SiteManager.handleClick → preventDefault + stopPropagation
       └─ eventBus.emit('open-page', {url,title})
            ├─ storageManager.addHistory(...)
            └─ PopupManager.open({url,title})
                 ├─ popup.show(title,url)          // 构建/显示面板
                 └─ LoaderManager.load(url,{...})
                      ├─ resolveMode(url,hostname) → 站点策略/默认模式/缓存
                      └─ 对应 loader.load(...)
                           ├─ iframe：注入 iframe
                           ├─ request/cache：抓取→sanitize→renderIntoIframe
                           └─ parser：抓取→sanitize→DOM 解析渲染
  └─ 渲染后：fixLinks / injectReadStyle / fixImages
```

### 3.2 悬停预热数据流

```
mouseover → SiteManager.resolveCandidate → PrefetchManager.schedule(url,hostname)
  ├─ 仅当 resolveMode==='cache' 且未缓存时
  └─ 防抖 150ms → loader.prefetch(url)（抓取+净化+写缓存）
```

### 3.3 弹窗内链接（拦截关闭时）

```
弹窗内容区 click → PopupPanel 内容点击监听
  ├─ 仅当 linkIntercept===false 时生效
  └─ 找到 a[href]（非 javascript:/#）→ preventDefault
       └─ handlers.onOpenInWindow(url, text) → 更新标题/URL → load(url) 窗内加载
```

## 4. 加载方式决策

```
resolveMode(url, hostname):
  1. sandbox.policyFor(hostname).iframe === true  → 'iframe'   （白名单直载）
  2. config.loader.defaultMode                     → 强制指定模式
  3. config.cache.enabled === true                 → 'cache'    （默认路径）
  4. 否则                                            → 'request'
```

`policyFor` 支持子域名匹配（如 `www.1cili.com` 命中 `1cili.com` 策略）；未知站点回退 `unknown` 策略（`{iframe:false, scripts:false}`）。

`sitePolicy` 现状：`linux.do`、`1cili.com`、`s.9cili.mom` 三个站点有白名单条目，其余走 unknown。

## 5. 安全模型

三层纵深：

| 层 | 组件 | 机制 |
|---|---|---|
| ① 入口校验 | `UrlResolver` | 只放行 http(s)；拦截 `javascript:`/`data:`/`vbscript:`/`file:`；非同页锚点才拦截 |
| ② 内容净化 | `Sanitizer` | 移除 script/iframe/form 等；删 `on*` 事件；`href`/`src` 协议白名单；`srcdoc` 剥离；data: URI 图片放行 |
| ③ 渲染隔离 | `Sandbox` | 抓取渲染一律进 sandbox iframe；非信任站点不含 `allow-scripts`/`allow-same-origin`；信任站点（`scripts:true`）才保留脚本 |

**信任边界**：`sitePolicy` 是唯一信任源。`scripts:true`（保留脚本）与 `iframe:true`（直载）都必须显式配置，unknown 站点两者皆否。

## 6. 图片处理

懒加载识别覆盖两类主流模式，两处执行（净化阶段 + 渲染后兜底）：

- **data 属性模式**：`data-src` / `data-original` / `data-lazy-src` / `data-actualsrc` 等 16 个属性；`data-srcset`/`data-original-set` 单独处理。
- **Discuz 附件模式**（v2.0.5 新增）：`src` 为 1x1 `none.gif` 占位，真实地址在 `zoomfile`/`file` 属性；`fixImages` 增加占位图文件名判定（`none.gif`/`placeholder`/`loading` 等），避免 `naturalWidth=1` 绕过 `naturalWidth===0` 判定。
- **兜底**：渲染后 0ms/1500ms/3500ms 三轮 `fixImages`，已失败图片强制 `eager` 重试。
- **绝对化**：以 `<base>` 与页面 URL 为基准，把相对图片地址与 CSS 样式链接绝对化。

## 7. 扩展点

| 扩展点 | 方式 |
|---|---|
| 新增站点适配器 | 新建 `src/adapters/X.js` 继承 `BaseAdapter`，在 `main.js` `registerAdapters()` 注册 |
| 新增自定义增强 | `siteManager.registerEnhancer(fn)` |
| 新增加载方式 | 新建 loader 注册进 `LoaderManager.loaders`，并在 `resolveMode` 加分派分支 |
| 站点加载策略 | 改 `config.sitePolicy`（iframe/scripts 白名单） |
| 其他脚本复用弹窗 | 引用 PopupKit（`window.PopupKit`） |

> 注意：无自动发现机制，新适配器必须手动 import + register 一次（见《03 开发实现方案》）。

## 8. 状态与存储

| 数据 | 键 | 归属 | 说明 |
|---|---|---|---|
| 全局设置 | `pv2:settings` | 全局 | theme / allowInFrame |
| 站点设置 | `pv2:siteSettings` | 按 hostname | scrollbarVisible / panelSize / windowMode / linkIntercept / phoneModel / phonePosition |
| 链接规则 | `pv2:rules` | 按 hostname | CSS 选择器列表 |
| 历史 | `pv2:history` | 全局 | 最多 100 条，去重 |
| 收藏 | `pv2:favorites` | 全局 | 去重 |

持久化经 `gm.getValue/setValue`，无 GM 时落到 `localStorage`（前缀 `popup-viewer:`）。
