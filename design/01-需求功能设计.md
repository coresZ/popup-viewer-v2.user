# 01 需求功能设计（Popup Viewer V2）

> 对应版本：v2.0.5 · 本文档描述现状实现，面向新维护者与功能评审。
> 技术细节见《02 架构方案》《03 开发实现方案》。

## 1. 产品概述

**Popup Viewer V2** 是一个 Tampermonkey 用户脚本（油猴脚本）。点击论坛/帖子链接时，不再跳转新页面，而是在当前页面内弹出独立阅读窗口加载内容。插件化架构，内置多站点适配器，并支持「链接规则」让任意网站都能配置要拦截的链接。

- **形态**：单文件用户脚本（`dist/popup-viewer-v2.user.js`），无运行时依赖，esbuild 打包。
- **运行时**：Tampermonkey 等支持 `GM_*` API 的脚本管理器；无 GM 时自动降级为 `fetch`/`localStorage`。
- **目标用户**：常逛论坛、需要在同一页面快速连续阅读多篇帖子的用户。

## 2. 用户与使用场景

| 场景 | 说明 |
|---|---|
| 逛论坛列表 | 在帖子列表页（如淘股吧 `/bbs/`、52pojie 版块页）点击标题，弹窗内阅读，不离开列表 |
| 对比多帖 | 通过关闭/刷新/在新标签页打开，快速在数篇帖子间切换 |
| 内容受限站点 | 需要保留登录态/脚本的站点走 iframe 直载（如 linux.do）；需净化安全的站点走抓取渲染 |
| 任意网站 | 无内置适配器时，用「取选新链接」自行配置拦截规则 |
| 手机阅读 | 通过手机模式预设小窗体尺寸并携带移动端 UA 抓取，模拟手机端页面 |

## 3. 功能清单

### 3.1 弹窗阅读（核心）

- 拦截页面内匹配规则的链接点击，在弹窗中加载内容，不跳转。
- 两种驻留方式：
  - **跟随页面**：弹窗带遮罩（overlay），点击遮罩关闭。
  - **独立悬浮**：无遮罩、页面可交互，弹窗悬浮于页面之上。
- 弹窗头部工具栏：刷新（R）、全屏（F）、新标签页打开、设置、关闭（Esc）。
- 底部显示当前 URL，可一键新标签页打开。
- 双击标题栏切换全屏。
- 快捷键：`Esc` 关闭 · `F` 全屏 · `R` 刷新。

### 3.2 多站点适配

内置适配器（`src/adapters/`）：

| 适配器 | 站点 | 说明 |
|---|---|---|
| Discuz | chiphell.com · wnflb2023.com · 52pojie.cn | Discuz! 论坛，列表页 `a.xst` 链接 |
| 淘股吧 | www.tgb.cn · shuo.tgb.cn | 板块列表（新旧布局）、博客、实盘比赛、快讯 |
| LinuxDo | linux.do | Discourse 系，`a.title.raw-topic-link` 链接 |
| 磁力站 | 1cili.com · s.9cili.mom | 磁力列表 `tr > td:first-child a` |

### 3.3 链接规则（任意网站）

- 对任意网站按 hostname 存储链接规则（CSS 选择器列表）。
- 「取选新链接」：页面上点一下要拦截的链接 → 自动生成候选选择器 → 确认。
- 规则仅对当前站点生效，可增删，实时匹配数提示。

### 3.4 多种加载方式

按站点策略/配置自动选择：

| 方式 | 说明 |
|---|---|
| iframe 直载 | 直接 iframe 加载目标页，保留页面脚本与登录态（白名单站点） |
| 抓取净化渲染 | `GM_xmlhttpRequest` 抓取 → 安全净化 → 渲染进沙箱 iframe |
| 解析渲染 | 抓取净化后直接解析 DOM 渲染进弹窗容器（不套 iframe） |
| 缓存 | 抓取净化后进内存缓存，命中直接渲染（30 分钟 TTL） |

### 3.5 手机模式

- 预设 iPhone / Max / 安卓 / 小屏四种手机窗体尺寸。
- 携带对应移动端 UA 抓取，模拟移动端页面渲染。
- 手机模式窗体位置可记忆（持久化）。

### 3.6 窗体大小预设

小 / 中 / 大 / 手机四种尺寸，可记忆拖动位置，始终约束在可视区域内。

### 3.7 视口自适应

- 窗体尺寸与位置用 `min()` 联动 `100vw/100dvh`，打开 DevTools 或缩放窗口时自动收缩并拉回可视区。
- 弹窗内容滚动到底不再连带滚动外部页面（`overscroll-behavior` + `wheel` 兜底）。

### 3.8 页面链接拦截开关

- 开启：页面链接点击在弹窗内打开。
- 关闭：页面链接原页面打开；弹窗内容里的链接在窗体内部打开（禁止新标签页）；窗体自动切换为独立悬浮。

### 3.9 高级：在 iframe 中运行（默认关闭）

- 默认只在顶层页面运行（等价 `@noframes`）。
- 开启后脚本在页面内所有 iframe 运行，可能增加开销、出现多个悬浮按钮或样式冲突，仅在确有需要时开启。

### 3.10 设置持久化

- 全局设置（跨站点）：主题、在 iframe 中运行。
- 站点设置（按 hostname 分别记录）：滚动条显隐、窗体大小、驻留方式、链接拦截开关、手机型号、手机位置。

### 3.11 明暗主题

跟随系统（auto）或手动指定浅色/深色，全局共享。

## 4. 交互流程

### 4.1 点击打开弹窗

```
用户在列表页点击链接
  → 全局 click 捕获（capture 阶段）
  → 优先查用户规则，其次内置适配器解析
  → URL 安全校验（http(s)、非危险协议、非同页锚点）
  → 命中：preventDefault + stopPropagation
  → 记录历史 → 打开弹窗 → 加载内容
```

### 4.2 悬停预热

```
鼠标悬停候选链接
  → 解析候选（同点击解析逻辑，不修改事件）
  → 若解析结果为缓存模式且未缓存：防抖 150ms 后台抓取
  → 点击时命中缓存立即渲染
```

### 4.3 取选新链接

```
打开链接规则面板 → 点击「取选新链接」
  → 进入取选模式：悬停高亮元素 + 提示条
  → 单击元素 → 生成候选选择器（id/class/父级范围/nth-child 路径，按匹配数排序）
  → 候选按钮 / 可编辑输入 / 实时匹配数 → 确认
  → 存为该站点规则 → 列表刷新
```

### 4.4 设置面板

- 右下角悬浮齿轮按钮，或在弹窗工具栏打开。
- 分段控件（窗体大小/主题/驻留方式/手机型号）、开关（滚动条/拦截/iframe）、说明 tooltip、恢复默认。

## 5. 边界与非目标

- **不重写页面**：只增强链接行为，不改变页面布局与内容。
- **不代替翻页**：只拦截可识别为帖子的链接，不做列表翻页聚合。
- **不做持久化缓存**：内容缓存仅内存级（30 分钟 TTL，50 条上限），刷新页面即失效。
- **不解析全部站点**：无内置适配器的站点靠用户自配规则；解析失败允许新标签页兜底。
- **不承诺全量图片可显示**：依赖站点图片 URL 模式被净化器识别；无法识别的懒加载模式以失败兜底处理。

## 6. 约束与假设

- **安全沙箱**：抓取渲染必须在 iframe sandbox 中执行；非白名单站点剥离 `<script>` 与事件属性。
- **零样式污染**：主脚本样式 `popup-`/`pv-` 前缀；PopupKit 用 `pvk-` 前缀；`@layer` 隔离 + 固定容器盒模型兜底，抵御宿主页面 CSS 干扰。
- **GM API 降级**：无 `GM_addStyle`/`GM_xmlhttpRequest`/`GM_getValue`/`GM_setValue` 时分别降级为 `injectStyle`/`fetch`/`localStorage`。
- **iframe 默认不运行**：`allowInFrame=false` 时等同 `@noframes`，避免在广告/嵌入 iframe 中重复初始化。

## 7. 术语表

| 术语 | 含义 |
|---|---|
| 适配器（Adapter） | 针对某类站点的解析/增强实现，继承 `BaseAdapter` |
| 链接规则（Rule） | 用户为某站点配置的 CSS 选择器，命中即在弹窗打开 |
| 净化（Sanitize） | 剥离脚本/事件/危险协议等，保留安全内容 |
| 沙箱（Sandbox） | 受限 iframe 执行环境，控制脚本与同源权限 |
| 预热（Prefetch） | 悬停时后台抓取并缓存，点击立即渲染 |
| PopupKit | 把弹窗能力封装成的独立库脚本，供其他脚本 `@require` 使用 |
