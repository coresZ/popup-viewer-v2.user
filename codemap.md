# popup-viewer-v2/

## Project Responsibility
A Tampermonkey userscript (Popup Viewer V2 / 页内弹窗打开新帖) that enables in-page popup preview of forum posts and links. It intercepts link clicks and loads content in a sandboxed popup panel without navigating away from the current page. Features multi-site adapters, user-defined link rules, multiple loading strategies, a standalone PopupKit library, and an X (Twitter) native reader.

## System Entry Points
- `src/main.js`: Userscript entry point — initialization, adapter registration, event wiring, userscript menu, X bridge installation.
- `src/kit/popupKit.js`: Standalone PopupKit entry; bundles into `dist/popup-viewer-kit.js` and exposes `window.PopupKit`.
- `build.mjs`: esbuild build script producing both dist artifacts.
- `banner.txt`: Userscript metadata header (`@name`, `@version`, `@include`, `@grant`, `@connect`, `@run-at`).
- `package.json`: Dependency manifest, version source for `__PV2_VER__`, npm scripts.

## Architecture Overview
The system follows a modular manager-based architecture with singleton instances:
1. **Initialization**: `main.js` loads settings, registers adapters, optionally installs the X GraphQL bridge, and wires event handlers.
2. **Site Detection**: `SiteManager` matches current hostname/pathname against registered adapters and user rules (rules take priority).
3. **Click Handling**: `SiteManager.handleClick()` → `resolveCandidate()` → emits `open-page` event.
4. **Popup Opening**: `PopupManager.open()` → `LoaderManager.load()` → appropriate loader fetches content.
5. **Content Loading**: Loaders fetch, sanitize, and render content into sandboxed iframes or direct DOM, depending on site policy.
6. **Security**: All fetched content passes through `Sanitizer` and `Sandbox`; URLs pass `UrlResolver`.
7. **UI Isolation**: The popup shell is mounted in an open Shadow DOM (`src/utils/uiHost.js`) with a page-mount fallback.

## Data Flow
- **User Click**: Adapter/Rule parsing → URL validation → event bus → popup manager → loader → renderer.
- **Settings**: User changes → `SettingsManager` → persistence via GM storage (global `pv2:settings` + per-site `pv2:siteSettings`) → UI updates.
- **Rules**: User-defined selectors → `RulesManager` (`pv2:rules`) → persistence → integrated into click resolution before adapters.
- **History / Favorites**: `StorageManager` persists `pv2:history` / `pv2:favorites`.
- **X**: Page-context GraphQL bridge → `XThreadLoader` → `xModel` parsing → `xRender` native DOM rendering.

## Build & Distribution
- `npm run build` → `dist/popup-viewer-v2.user.js` (from `src/main.js`) + `dist/popup-viewer-kit.js` (from `src/kit/popupKit.js`).
- `npm run build:min` for minified output; `npm run dev` for watch mode.
- `npm test` runs the pure-logic regression suites.
- See [docs/development.md](docs/development.md) for full build, test, extension and release documentation.
