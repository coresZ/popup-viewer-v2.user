## 2. 本轮做了什么

**评论抽屉**：点评论行 → 从**右侧滑入**展示「这条评论 + 它的回复」，可逐级下钻。

- 触发：整行可点（点击**委派**在阅读器上，不逐行绑定）；点链接/按钮/视频/输入框/引用卡不触发；**正在选中文字时不触发**；点原帖本身不触发
- 抽屉：宽 `min(72%, 620px)`、右对齐、内部**单栏纵向**（评论在上、回复在下）；右滑入 / 右滑出
- **不遮住回复框（本轮最后一条需求）**：抽屉起点 = 回复输入框的**底边**（JS 量取），因此上方的「评论数 / 排序 / 在 X 打开」行与**回复输入框始终露出且可继续输入**；输入多行撑高时用 `ResizeObserver` 跟随
- **非模态**：不加遮罩；层 `pointer-events: none`，只有抽屉面板吃点击 → 左栏原帖仍可点、可滚动，抽屉开着时点别的评论/祖先帖可直接切换内容
- 键盘：打开即聚焦抽屉，`Esc` 先关抽屉/回退、**不会把整个弹窗关掉**
- 只读为主：赞/转/藏/分享沿用现有接线可用；**「回复」按钮被移除**（回复框在抽屉背后那一栏，点了看不见）
- 加载：进入显示加载态，失败给错误 + 重试；结果按帖子 ID 缓存
- 层级重排：**抽屉 7 / 资料卡 8 / 大图灯箱 9 / toast 10**（否则抽屉里点图，灯箱会开在抽屉背后）
- 清理：不注册任何 document 全局监听，随弹窗销毁零残留；`prefers-reduced-motion` 下取消滑入动画

## 3. 测试关注点（建议按此清单走）

1. 点评论行 → 抽屉从**输入框下方**滑入；输入框与排序行**没被盖住**
2. 在输入框里输入多行 → 抽屉起点跟着下移，始终不盖住输入框
3. 左栏原帖仍可选文字/滚动；抽屉开着时点另一条评论 → 内容**切换**而不是叠加
4. `Esc`：只关抽屉；抽屉内 `‹` 逐级返回
5. 抽屉里点图 → 大图灯箱出现在**抽屉之上**；悬停作者 → 资料卡也应在抽屉之上
6. 抽屉里点 @提及 / 链接 → 走各自链接，不触发下钻
7. **回归面**：单栏（窄弹窗/手机）布局、媒体轮播的左右滑动、引用卡位置（正文→图片→引用卡）、面板切尺寸预设后的定位、切换手机↔小/中/大
8. 关闭弹窗再打开另一条帖子 → 不应有残留（观察是否有异常请求或 DOM 残留）

## 4. 已知限制 / 未做

- 抽屉内的评论**不参与翻译**；**不能回复**；回复列表**不分页**（只显示该层响应里带回的回复）
- HLS 自适应播放未做（hls.js 约 +200KB，需先确认）
- 翻译默认开启、目标语言固定 `zh-cn`，没有设置项
- 评论里的长文只显示紧凑卡片，正文不展开
- 引用卡只显示两行正文/标题，完整内容需点开新窗口
