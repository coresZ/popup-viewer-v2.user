## 1. 键盘与焦点

### K1 · P0 · 全局单字母快捷键劫持输入【实测】
- 现象（弹窗可见时）：
  - 宿主搜索框输入 `fork` 得到 `fok`，面板同时切成全屏
  - 点选输入框输入 `forum` 得到 `foum`，面板从 713×675 变成 1440×900
  - X 回复框输入 `ok` 后按 `r`：输入框清空，阅读器重建，焦点落到 BODY
  - `Ctrl+F` 也会切全屏；回复框里按 Esc 会关窗，350ms 后清空内容区
- 原因：`src/ui/PopupPanel.js:566–588` 只判断弹窗是否可见，不判断焦点目标、`isComposing`、修饰键；`f` 分支连修饰键都不查。`src/kit/KitPopupPanel.js:219` 是同一段逻辑。X 回复框的 keydown 只处理 Ctrl+Enter，不阻止冒泡（`src/x/xRender.js:1026–1032`）
- 修复：handler 开头遇到 `defaultPrevented`、`isComposing`、修饰键或可编辑目标直接 return；Esc 在可编辑目标里只失焦。回复框有草稿时，关窗或刷新前先确认或暂存

### K2 · P0 · 隐藏的界面能拿到键盘焦点【实测 + 代码】
- 现象：Tab 会进入隐藏的面板按钮（8 个）、设置面板（31 个）、规则面板（2 个），按 Enter 照样触发。「恢复默认」没有确认（`src/ui/SettingsPanel.js:196–211`）
- 原因：启动时就调用 `ensure()` 建好界面（`src/main.js:294`），脚本匹配 `*://*/*`；隐藏态只有 `opacity:0; pointer-events:none`（`src/ui/style.css:170–171`，设置弹层、规则遮罩、规则面板、toast 同理）
- 修复：隐藏态加 `visibility:hidden`（淡出结束后再切换），JS 同步设置 `inert`

### K3 · P1 · 焦点在帖子 iframe 里时快捷键全部失效【代码】
- 原因：监听只挂在宿主 document（`src/ui/PopupPanel.js:590`）
- 修复：同源 iframe 加载后给它的 document 挂 keydown 并转发（复用 K1 的判断）

### K4 · P1 · 从悬浮齿轮打开的设置面板按 Esc 关不掉【实测】
- 原因：`src/ui/PopupPanel.js:567` 面板不可见时直接 return；设置面板自己的 Esc 只关说明气泡（`src/ui/SettingsPanel.js:65–67`）
- 修复：设置弹层自己处理 Esc；打开时焦点移入，关闭时还给触发按钮

### K5 · P1 · 焦点框被重置样式去掉【代码 + 实测】
- 原因：`src/ui/style.css:32` 重置层写了 `outline:0`。没有补回 `:focus-visible` 的有：悬浮齿轮、设置关闭按钮、「说明」、规则删除按钮、「取选新链接」、规则面板关闭按钮、点选候选项和按钮。已有的焦点环是半透明色，对背景约 1.8:1（浅）/ 2.7:1（深），低于 3:1
- 修复：外壳根统一 `:focus-visible{outline:2px solid var(--popup-accent);outline-offset:2px}`，`forced-colors` 下用 `CanvasText`

## 2. 标题、历史与底部栏

### N1 · P1 · 标题变成 "Content"，后退能点但无效，底部提示指向宿主页【实测】
- 现象：打开第一帖后，标题为 `Content`，iframe 地址等于宿主页 `/forum?reset`，后退按钮可用；连点两次后退，宿主地址、弹窗、iframe 内容都不变。底部链接按钮实际打开的是正确的 `/thread/1`
- 原因：`src/loaders/IframeRenderer.js:80` 模板写死 `<title>Content</title>`；document.write 之后 iframe 地址等于宿主页地址，第二次 load 被当成弹窗内跳转上报（`IframeRenderer.js:57–68`），`readIframeLocation` 只排除了 `about:blank`（`:10–24`）
- 影响范围：默认的缓存/抓取加载方式（大多数站点）每打开一篇帖子都会出现
- 修复：上报前若地址等于宿主页地址则忽略；模板标题用抓到的 `<title>`；收到占位标题时保留原标题

### N2 · P2 · 底部栏用处小【实测】
- 默认开启链接拦截时，帖内链接全部 `target="_blank"`（`IframeRenderer.js:100–103`，抽查 4/4），← → 基本没有历史可走；外链按钮与顶部重复；原来的地址文字换成了图标（`PopupPanel.js:69–91`），看不出在哪个站
- 修复：显示域名；没有历史时隐藏 ← →

### N3 · P2 · 产品建议：帖内链接默认在弹窗内打开
- Ctrl/中键再新开标签页，让前进后退有意义。需要产品决定

## 3. 点选与规则

### R1 · P1 · 默认候选选中整块容器，劫持同块里的其他链接【实测】
- 现象：点帖子标题时默认候选是 `.main`；用这条规则后，点同一行的作者「山野」打开的是帖子
- 原因：`src/utils/selector.js:120–130` 匹配数相同时按选择器长度排序；`src/core/RulesManager.js:91–96` 命中容器后取容器里第一个链接
- 修复：点到的是链接时，优先推荐只匹配链接本身的选择器，「整行可点」单列并说明；命中容器但点击目标在另一个链接上时不拦截

### R2 · P1 · 点选时弹窗仍挡在页面中央【代码 + 实测】
- 原因：`src/ui/RulesPanel.js:110–111` 只收起规则面板，弹窗（实测 720×675）和遮罩还在
- 修复：点选期间隐藏弹窗和遮罩，结束后恢复

### R3 · P1 · 触屏点选几乎不可用【实测】
- 现象：手指滑动松开就算选中；提示语是"移动鼠标高亮…Esc 取消"（`src/ui/ElementPicker.js:247`）；提示条不接收点击（`:39`），没有取消入口
- 修复：位移超过约 10px 的触摸不算点选；触屏专用文案；提示条加可点的「取消」

### R4 · P2 · 确认框候选无法区分
- 8 个候选都写"12 个"，原始选择器对普通用户没有意义
- 修复：选中候选时高亮页面上所有命中；用通俗描述，原始选择器收进"高级"

### R5 · P2 · 规则面板能力弱
- 只看当前站点，只显示选择器，不能编辑或停用；删除二次确认只是变红（`src/ui/style.css:917–921`），删除后不能撤销
- 修复：确认态显示"再点一次删除"，删除提示带撤销；后续加编辑、停用、全部站点视图

## 6. 视觉与样式（弹窗外壳）

### V1 · P1 · 次要文字对比度不足【实测】
- `--popup-faint` 用在 11–13px 文字上（分组标题、设置说明、规则提示、加载副标题等）：浅色 2.47–2.56:1，深色 3.5–3.75:1
- 修复：文字改用 `--popup-muted`，最小 12px；`--popup-faint` 只用于分隔线和禁用态

### V2 · P1 · 强调色、危险色上写死白字【实测】
- 深色主题 #60a5fa 上白字 2.54:1，hover 约 1.8:1（如 `#pv-rules-pick`、错误页按钮、点选「确认」）
- 修复：新增 `--popup-on-accent`（浅 #fff / 深 #0f172a）

### V3 · P1 · 宿主 CSS 渗入弹窗【实测 + 代码】
- 重置写在 `@layer pv-reset`（`src/ui/style.css:7–46`），宿主不分层的规则会覆盖它；外壳根没有固定字号、行高。实测错误页标题 16.1px、设置按钮高 31px，都随测试站 `body{font:14px/1.6}` 变化；错误视图的 h3、p 没有颜色
- 修复：短期在外壳根固定 font、line-height、letter-spacing，错误/加载视图显式写颜色；长期迁入 Shadow DOM

### V4 · P1 · 触屏热区偏小，开关没有可访问名称【实测】
- 页脚 ← → 外链 30×30（页头已是 44×44，页脚被单独压回）、设置关闭 30×30、规则删除 28×28、「说明」16×16、开关 38×22、分段和标签页 31px 高；开关文字不在 `<label>` 里

### V5 · P1 · 触屏四角缩放把手挡住网页四角【代码】
- 36×36 不透明把手默认常驻（`src/ui/style.css:224–253`），手机上面板几乎全屏
- 修复：窄屏默认关闭，或改成半透明小角标

### V6 · P2 · 非文本对比度
- 点选输入框边框约 1.24:1；开关关闭态约 1.43:1；页脚禁用按钮叠加 `opacity:.35` 后约 1.3:1

### V7 · P2 · 层级

### V8 · P2 · 颜色变量纪律
- 28 处写死颜色（12 处被下一行覆盖不生效）；阴影只有浅色版；iframe 写死白底，深色主题加载时闪白；深色变量在 style.css 写了两份，kit.css 还有一份

### V16 · P2 · 组件细节

### V17 · P2 · 入口单一
- 只有右下角固定齿轮，没有油猴菜单命令（`banner.txt` 未 grant `GM_registerMenuCommand`），齿轮不能移动或隐藏；新站点添加第一条规则需要 5 步
