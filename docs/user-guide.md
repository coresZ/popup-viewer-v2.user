# Popup Viewer V2 用户使用手册

> **适用版本：v2.3.7**（2026-10-31）<br>
> **产品名称：** Popup Viewer V2（页内弹窗打开新帖）<br>
> **项目仓库：** [coresZ/popup-viewer-v2.user](https://github.com/coresZ/popup-viewer-v2.user) · **License：** MIT

Popup Viewer V2 是一款用户脚本（Userscript）。安装后，在论坛、社区或 X（Twitter）页面上点击帖子/文章链接，内容会直接在当前页面弹出的阅读窗口里打开，不再跳转离开当前页面。

> 相关文档：[项目 README](../README.md) · [开发手册](development.md) · [更新日志](../CHANGELOG.md)

## 1. 认识 Popup Viewer V2

### 1.1 它能做什么

- **页内弹窗阅读**：点击帖子、文章或资讯链接时，不再整页跳转，而是在当前页面上方弹出一个可拖动、可缩放的阅读窗口。
- **多站点适配**：内置 Discuz 论坛、淘股吧、linux.do、磁力站和 X（Twitter）的点击解析规则，安装后即可在对应站点使用。
- **任意网站扩展**：通过「链接规则」在任意网站上点选链接，自动生成拦截规则，不需要写代码。
- **接近原站的阅读体验**：自动处理懒加载图片；可切换遮罩/悬浮、深浅主题、手机模式；X 站点还提供专用的双栏阅读器。
- **移动端可用**：支持 Android Firefox / Kiwi 与 iOS Safari（Tampermonkey / Userscripts 扩展），触屏按钮和手势做了适配。

### 1.2 支持的站点

| 站点类型 | 支持的域名 / 入口 | 说明 |
| --- | --- | --- |
| Discuz 论坛 | `chiphell.com`、`wnflb2023.com`、`52pojie.cn` | 点击帖子列表中的标题链接时弹出 |
| 淘股吧 | `www.tgb.cn`（含 `/bbs/` 板块列表、博客、实盘比赛）· `shuo.tgb.cn/livenews/` | 点击帖子 / 博客 / 资讯标题时弹出 |
| LinuxDo | `linux.do` | 点击主题列表的标题链接时弹出；该站直接使用 iframe 加载，保留登录态 |
| 磁力站 | `1cili.com`、`s.9cili.mom` | 点击表格首列的链接时弹出 |
| X / Twitter | `x.com`、`twitter.com` | 使用 X 专用阅读器，需在 X 页面内且保持登录 |
| 任意网站 | 通过「链接规则」自行添加 | 点选链接即可生成当前站点的拦截规则 |

> **提示：** 内置适配器只会拦截对应站点的「帖子标题 / 文章标题」类链接，并不是把整站所有链接都改成弹窗。普通导航、用户主页、外链等仍按网站原本的方式打开。若需要拦截其它链接，请使用「链接规则」。

### 1.3 它是怎么工作的

- 脚本运行在网页顶层（默认不会注入页面内的 iframe），监听你在页面上的点击，把命中的链接交给弹窗加载。
- 内置适配器负责识别各站点「哪些链接是帖子」；用户添加的链接规则优先级更高，会先于内置适配器匹配。
- 弹窗会根据站点策略自动选择加载方式：有的站点直接用 iframe 加载（保留登录态和页面脚本），有的站点抓取页面并净化后渲染，X 则通过当前登录会话读取帖子数据后原生渲染。详见 [4.13 加载方式说明](#413-加载方式说明)。
- 所有设置、规则和历史都保存在浏览器本地，不会上传到任何服务器。详见 [11. 数据与隐私](#11-数据与隐私)。

## 2. 安装、更新与卸载

### 2.1 安装前准备

Popup Viewer V2 是用户脚本，需要先安装一个用户脚本管理器：

| 平台 | 推荐管理器 | 浏览器 |
| --- | --- | --- |
| Windows / macOS / Linux | [Tampermonkey](https://www.tampermonkey.net/) | Chrome、Edge、Firefox、Safari 等 |
| Android | Tampermonkey | Firefox、Kiwi Browser 等支持扩展的浏览器 |
| iPhone / iPad | Userscripts（App Store）或 Tampermonkey | Safari |

安装文件为仓库中的 [`dist/popup-viewer-v2.user.js`](../dist/popup-viewer-v2.user.js)。在脚本管理器中，脚本显示名称为「页内弹窗打开新帖」。

### 2.2 在电脑浏览器中安装（Tampermonkey）

1. 在浏览器的扩展商店安装 Tampermonkey，并确认扩展已启用。
2. 打开 Tampermonkey 管理面板，进入「实用工具」→「导入」，选择下载好的 `dist/popup-viewer-v2.user.js`。
3. 也可以新建一个用户脚本，把 `popup-viewer-v2.user.js` 的全部内容粘贴进去并保存。
4. 打开任意支持的站点（例如 `chiphell.com`），刷新页面。页面右下角出现齿轮按钮即表示安装成功。

> 如果脚本管理器询问是否允许脚本跨域访问网站，请选择允许。拒绝会导致抓取类站点无法加载内容，X 阅读器也无法工作。

### 2.3 在 iPhone / iPad 上安装（Userscripts）

1. 在 App Store 安装 Userscripts。
2. 打开「设置 → Safari → 扩展」，启用 Userscripts，并允许它访问你需要的网站。
3. 在 Userscripts 中导入 `dist/popup-viewer-v2.user.js`。
4. 用 Safari 打开支持的站点，刷新页面后即可使用。

> iOS 上部分页面的 `DOMContentLoaded` 事件可能不触发，脚本已加入约 1.5 秒的兜底初始化。若首次打开没有反应，等待片刻或刷新一次页面。

### 2.4 在 Android 上安装

1. 在 Firefox 或 Kiwi Browser 中安装 Tampermonkey 扩展。
2. 按 [2.2](#22-在电脑浏览器中安装tampermonkey) 的步骤导入 `dist/popup-viewer-v2.user.js`。
3. 打开支持的站点；移动端会自动使用适配小屏的弹窗布局。

### 2.5 更新脚本

1. 从项目仓库下载新版本的 `dist/popup-viewer-v2.user.js`。
2. 在脚本管理器中导入新文件，按提示覆盖同名脚本。Tampermonkey 会保留该脚本已有的本地设置与规则。
3. 刷新已打开的页面，新版本才会生效。可在 Tampermonkey 管理面板查看当前安装的版本号。

> 建议更新前阅读 [CHANGELOG.md](../CHANGELOG.md)，确认新版本的变化和已知问题。不同脚本管理器的覆盖操作略有差异；若先删除旧版再安装，脚本本地数据可能一并被清除。

### 2.6 卸载脚本

- **Tampermonkey**：打开管理面板，找到「页内弹窗打开新帖」，点击删除。
- **Userscripts**：在 Userscripts App 中左滑或进入编辑模式删除该脚本。
- 如需彻底清除本地数据，可在删除脚本前打开 Tampermonkey 的脚本存储页面清空数据（详见 [11.4 如何清除数据](#114-如何清除数据)）。

## 3. 快速上手

### 3.1 打开第一个帖子

1. 打开一个支持的站点，例如 Chiphell 的论坛版块列表。
2. 点击任意一个帖子标题。页面不会跳转，而是弹出阅读窗口。
3. 阅读完成后，点击弹窗右上角的 ✕、按 `Esc`，或在「遮罩」模式下点击弹窗外的空白处关闭。

如果没有弹出窗口，请先确认页面已刷新、脚本已启用，并参考 [10.1 点击链接没有反应](#101-点击链接没有反应)。

### 3.2 右下角齿轮

页面右下角的齿轮按钮是脚本的设置入口：

- 点击齿轮打开设置面板；设置面板分为「通用」「移动端」「最近」三个标签。
- 弹窗打开时，齿轮会暂时隐藏；此时可以点击弹窗工具栏里的齿轮按钮打开同一设置面板。
- 齿轮可以在当前站点隐藏，之后通过油猴菜单重新打开设置（见下一节）。

### 3.3 油猴菜单

在 Tampermonkey 的脚本菜单（浏览器扩展图标 → 本脚本）中提供三个命令：

| 菜单命令 | 作用 |
| --- | --- |
| 打开设置 | 打开设置面板；即使右下角齿轮已被隐藏也可以使用 |
| 在此站点点选链接 | 不经过设置面板，直接进入当前站点的链接点选模式 |
| 显示/隐藏右下角设置按钮（本站） | 切换当前站点是否显示右下角齿轮；按域名分别记忆 |

> 其中「显示/隐藏右下角设置按钮（本站）」会按当前域名记住，相当于一个站点级的界面开关，但不会出现在设置面板中。菜单命令只在浏览器顶层页面生效；在弹窗内部打开的页面里不会重复出现菜单。如果你的脚本管理器不提供菜单命令（例如部分移动端环境），使用右下角齿轮即可访问设置。

### 3.4 页面链接拦截总开关

设置 → 通用 →「页面链接拦截」是总开关：

- **开启（默认）**：点击命中的链接时在弹窗内打开。
- **关闭**：页面链接恢复网站原本行为；弹窗只能使用「悬浮」模式，不能使用遮罩。
- 重新开启后，窗体驻留方式仍停留在「悬浮」，需要手动切回「遮罩（点空白关闭）」。

## 4. 弹窗操作

### 4.1 界面构成

| 区域 | 内容 |
| --- | --- |
| 标题栏 | 当前帖子标题；拖动它可移动窗体，桌面端双击可切换全屏 |
| 工具栏 | 刷新、全屏、在新标签页打开、设置、关闭 |
| 内容区 | 加载的帖子 / 页面内容 |
| 底部栏 | 后退、前进、当前站点域名、在新标签页打开 |

> 标题过长时，鼠标悬停在标题上可查看完整标题。

### 4.2 拖动窗体

- 按住标题栏（不要按到按钮）拖动窗体；鼠标和触屏都支持。
- 松开后窗体会自动约束回可视区域内，不会被拖出屏幕。
- 锁定窗体后不能拖动，详见 [4.11 锁定窗体](#411-锁定窗体)。

### 4.3 调整窗体大小

- 拖动窗体的四边或四角即可自由缩放，最小尺寸为 **260 × 200**。
- 桌面端缩放把手在鼠标移到边缘时出现；触屏端可以在「移动端」设置中开启四角缩放把手。
- 缩放后的尺寸会作为「自定义」大小按站点记住；重新点击任意一个大小预设即可恢复预设尺寸。
- 窗口尺寸变化（如打开开发者工具、缩放浏览器窗口）时，弹窗会自动收缩并拉回可视区域内。

### 4.4 全屏阅读

- 点击工具栏的全屏按钮，或按 `F`，让弹窗铺满浏览器可视区域。
- 桌面端还可以双击标题栏切换全屏。
- 再次点击按钮或按 `F` 恢复原来的大小和位置。

> 这里的「全屏」是弹窗铺满浏览器可视区域，不是按 `F11` 进入的浏览器全屏。

### 4.5 刷新内容

- 点击工具栏的刷新按钮，或按 `R`，重新加载当前弹窗里的内容。
- 刷新会保持窗体的位置和大小，不会重置你的尺寸设置。

### 4.6 在新标签页打开

- 点击工具栏的「在新标签页打开」按钮，或点击底部栏右侧的链接图标，会在浏览器新标签页打开当前弹窗里的地址。
- 如果内容加载失败或显示不完整，这是最可靠的备用方式。

### 4.7 弹窗内前进 / 后退

- 底部栏的 ←、→ 按钮控制弹窗内部的历史记录，不会影响外层页面。
- 对支持同源 iframe 的站点，脚本会优先调用 iframe 自己的浏览器历史；SPA（单页应用）站点的内部跳转也能记录。
- 没有可前进/后退的记录时，这一组按钮会隐藏。
- 快捷键：`Alt + ←` 后退，`Alt + →` 前进。

### 4.8 遮罩与悬浮

设置 → 通用 →「窗体驻留方式」有两种模式：

| 模式 | 行为 | 适合的场景 |
| --- | --- | --- |
| 遮罩（点空白关闭） | 弹窗背后有半透明遮罩，页面暂时不可操作；点击弹窗外空白处关闭 | 专注阅读，不想误触原页面 |
| 悬浮（不挡页面） | 没有遮罩，原页面仍可操作；点击页面上的链接仍会在弹窗内打开 | 边看原页面边阅读，或多任务对照 |

> 关闭「页面链接拦截」后，只能使用悬浮模式；设置里的「遮罩」选项会置灰并提示原因。

### 4.9 窗体大小预设

| 预设 | 尺寸 | 说明 |
| --- | --- | --- |
| 小 | 40% × 60% | 适合快速预览 |
| 中（默认） | 50% × 75% | 默认大小 |
| 大 | 72% × 90% | 接近全屏阅读 |
| 手机 | 按「手机型号」的像素尺寸 | 详见 [4.10 手机模式](#410-手机模式) |
| 自定义 | 你拖动缩放后的尺寸 | 仅在你调整过大小后出现，不能直接点选 |

- 尺寸按站点分别保存，不同网站可以使用不同的大小。
- 在设置里点击某个预设，会立即应用并清除之前的「自定义」尺寸。
- 在触屏小屏设备上（视口宽或高不超过 560 像素），非「手机」预设会自动铺满接近整个屏幕，以保证可读性。

### 4.10 手机模式

1. 打开设置 → 通用 →「窗体大小」，选择「手机」。
2. 下方会出现「手机型号」，可选择 **iPhone（393 × 852）**、**Max（430 × 932）**、**安卓（412 × 915）**、**小屏（360 × 780）**。
3. 手机模式下拖动窗体后，下次打开会记住位置。
4. 手机模式会为抓取类加载携带对应的移动端 User-Agent，以便站点返回移动版页面。

> 直接 iframe 加载的站点无法由脚本修改 User-Agent，因此手机模式的 UA 只对抓取 / 净化加载路径生效。

### 4.11 锁定窗体

- 打开设置 → 通用 →「锁定窗体」后，窗体不能拖动、也不能缩放，避免阅读时误操作。
- 锁定不影响工具栏按钮、关闭弹窗和页面滚动。
- 该设置同样按站点记住。

### 4.12 关闭弹窗

- 点击工具栏右上角的 ✕。
- 按 `Esc`（焦点不在输入框时）。
- 在「遮罩」模式下点击弹窗外空白处。
- 关闭后，弹窗内历史会清空；再次打开同一帖子会重新加载内容。

### 4.13 加载方式说明

脚本会根据站点自动选择加载方式，不需要手动切换：

| 加载方式 | 工作方式 | 常见站点 |
| --- | --- | --- |
| iframe 直载 | 直接把目标页面放进弹窗，保留登录态、页面脚本和原生交互 | `linux.do` 等站点 |
| 抓取净化 | 请求页面 HTML，移除脚本和危险内容后渲染，安全隔离 | 大多数未特别配置的站点、任意网站的链接规则 |
| 抓取并保留脚本 | 在沙箱 iframe 中保留必要脚本，尽量还原页面效果 | `1cili.com`、`s.9cili.mom` 等信任站点 |
| X 阅读器 | 通过当前 X 登录会话读取帖子数据，原生渲染 | `x.com`、`twitter.com` |

> 抓取净化模式无法保留目标网站的登录态，遇到需要登录才能查看的内容时，请点击「在新标签页打开」。

## 5. 设置项参考

### 5.1 打开设置与作用域

- **打开方式：** 右下角齿轮、弹窗工具栏的设置按钮，或油猴菜单「打开设置」。
- **三个标签：** 「通用」包含窗体行为、交互控制、外观和高级设置；「移动端」包含触屏相关设置；「最近」列出当前站点最近打开的帖子。
- **作用域：** 设置分为「全局」和「仅本站」两类：
  - **仅本站**：按当前网站的域名分别保存，只影响当前站点。
  - **全局**：所有站点共享同一个值。本版本中全局设置包括「外观主题」「在 iframe 中运行」「惯用手」「四角缩放把手」。

### 5.2 通用

| 设置项 | 控件 | 默认值 | 作用域 | 说明 |
| --- | --- | --- | --- | --- |
| 窗体驻留方式 | 分段：遮罩（点空白关闭）/ 悬浮（不挡页面） | 遮罩（点空白关闭） | 仅本站 | 遮罩模式点空白关闭；悬浮模式不挡页面。关闭「页面链接拦截」时只能选悬浮 |
| 窗体大小 | 分段：小 / 中 / 大 / 手机 / 自定义 | 中 | 仅本站 | 自定义仅在拖动缩放后出现，不能直接点选 |
| 手机型号 | 分段：iPhone / Max / 安卓 / 小屏 | iPhone | 仅本站 | 仅当「窗体大小」为「手机」时显示 |
| 窗体滚动条 | 开关 | 开 | 仅本站 | 显示或隐藏弹窗内容区的滚动条 |
| 锁定窗体 | 开关 | 关 | 仅本站 | 锁定后窗体不可拖动、不可缩放 |
| 页面链接拦截 | 开关 | 开 | 仅本站 | 关闭后页面链接按原样打开，弹窗只能悬浮 |
| 窗体内链接新标签页打开 | 开关 | 开 | 仅本站 | 开：弹窗内容里的链接在新标签页打开；关：在弹窗内部跳转 |
| 链接规则 | 按钮「管理」 | — | 仅本站（规则按域名保存） | 打开当前站点的链接规则管理，详见 [6. 链接规则](#6-链接规则) |
| 外观主题 | 分段：跟随系统 / 浅色 / 深色 | 跟随系统 | 全局 | 控制弹窗外壳、工具栏、设置面板等脚本界面的明暗主题；X 阅读器内部另跟随 X 自身主题 |
| 在 iframe 中运行 | 开关 | 关 | 全局 | 默认只在顶层页面运行；开启后脚本会在页面内所有 iframe 中运行 |
| 调试标记 | 开关 | 关 | 全局（独立存储） | 在页面上显示脚本运行状态与错误标记，下次刷新生效；仅排查问题时开启 |

> **风险提示：「在 iframe 中运行」默认关闭（等同于 `@noframes`）。** 开启后脚本会在页面内的所有 iframe（包括广告、嵌入内容等）中运行，可能增加页面开销、出现多个悬浮按钮，或与嵌入页面的样式产生冲突。脚本自己的弹窗 iframe 始终会跳过，不会出现「弹窗套弹窗」。仅在确有需要时开启。

### 5.3 移动端

| 设置项 | 控件 | 默认值 | 作用域 | 说明 |
| --- | --- | --- | --- | --- |
| 四角缩放把手 | 开关 | 关 | 全局 | 触屏下在窗体四角显示缩放把手，可自由调整窗体大小；手机弹窗接近全屏时默认关闭以免遮挡正文 |
| 惯用手 | 分段：右手 / 左手 | 右手 | 全局 | 左手模式镜像工具栏，关闭按钮移到左上角，方便单手操作 |

### 5.4 最近

「最近」页列出**当前站点**最近打开的 20 条帖子：

- 每条记录显示标题和相对时间（刚刚 / N 分钟前 / N 小时前 / N 天前 / 日期）。
- 点击任意记录，会在弹窗中重新打开该帖子；即使关闭了「页面链接拦截」，也可以通过这里打开弹窗。
- 点击「清空本站」需要二次确认：第一次点击后按钮变为「确认清空本站记录？」，3 秒内再次点击才会清空。
- 「清空本站」只删除当前域名的记录，不影响其他站点；底层历史最多保留 100 条。

### 5.5 恢复默认

设置面板底部有「恢复默认」按钮，采用两步确认：

1. 第一次点击：按钮变为「确认恢复全局+本站设置？」。
2. 在约 3 秒内再次点击：重置**全部全局设置**和**当前站点设置**。
3. 超过 3 秒未确认会自动取消。

> 「恢复默认」不会删除链接规则、最近打开记录和调试标记，也不会影响其他站点的设置。

### 5.6 设置保存与同步

- 所有设置保存在浏览器本地（GM 存储；无 GM 环境时回退到 `localStorage`），刷新页面不会丢失。
- 设置修改后立即生效并自动保存（「调试标记」除外，它需要刷新页面后生效），没有单独的「保存」按钮。
- 「仅本站」设置按域名分别保存；「全局」设置由所有站点共享。脚本不提供账号体系，不会在不同设备之间同步设置。
- 每个网站的设置互相独立，换站点后看到的是该站点自己的配置。

## 6. 链接规则

### 6.1 什么时候需要

内置适配器只覆盖常见站点和固定的帖子标题链接。以下情况可以使用链接规则：

- 你想在**任意网站**上把某类链接改成弹窗打开。
- 内置适配器没有覆盖你常逛的站点。
- 你只想拦截页面上的某一种链接，而不是整站全部链接。

### 6.2 用点选创建规则

1. 打开设置 → 通用 →「链接规则」，点击「管理」；也可以使用油猴菜单「在此站点点选链接」。
2. 在规则面板底部点击「点选链接」。面板会暂时收起，页面进入点选模式。
3. 移动鼠标（触屏上直接点按）到要拦截的链接上，目标元素会被高亮，顶部提示条会显示元素标签和可选的 class / id。
4. 单击（触屏点按）该链接。脚本会生成多个候选选择器，并弹出「要拦截哪些链接？」确认框。
5. 选择一个候选；如果候选不合适，展开「高级（CSS 选择器）」手动改写，或点击「重新选」再选一次。
6. 点击「确认」。规则会立即保存到当前站点，之后这类链接会在弹窗内打开。

> 点选过程中按 `Esc` 或点击提示条上的「取消」可以随时退出；触屏上滑动页面不会误选，只有点按才会选中。

### 6.3 选择候选选择器

确认框里的每个候选显示实际 CSS 选择器和「本页 N 个」命中数：

- 鼠标悬停在候选上可看到中文说明（例如「只拦截这类链接」「整行任意位置」）。
- 选中候选后，页面上所有命中的元素都会被框出，方便确认范围是否合适。
- **候选排序：** 优先显示命中链接本身的候选；「整块（整行任意位置可点）」容器候选排在最后。优先选择只命中目标链接的候选，避免把整行或无关链接也拦截。

### 6.4 管理规则

规则面板按当前站点列出规则，每条规则提供：

| 操作 | 方法 |
| --- | --- |
| 启用 / 停用 | 点击规则右侧的开关；停用后规则不参与匹配，但不会被删除 |
| 编辑选择器 | 点击「编辑」，修改后按 `Enter` 或「保存」；按 `Esc` 取消编辑 |
| 删除 | 第一次点击显示确认，再点一次删除；删除后 4 秒内可点击「撤销」恢复 |
| 查看命中数 | 当前站点会显示「本页匹配 N 个」；选择器无效时显示「选择器无效」 |

> 修改选择器时，如果与已有规则重复或为空，会提示保存失败；无效的 CSS 选择器会提示「选择器无效」。

### 6.5 全部站点视图

- 点击规则面板右上角的「全部站点」，可以查看所有配置过规则的域名。
- 每个站点显示规则总数，以及其中已停用的条数。
- 点击某个域名进入该站点的规则列表；点击「返回本站规则」回到当前站点。

### 6.6 规则优先级与注意事项

- 用户规则优先于内置适配器匹配；规则和适配器都命中时，使用规则。
- 规则只对**当前域名**生效，不会自动应用到子域名或其它站点。
- 规则只会打开 `http` / `https` 链接；`javascript:`、`#` 锚点等不会被拦截。
- 如果规则命中的是一个容器（例如整个帖子行），而你在容器内点击了另一个链接（例如作者名），脚本不会劫持该链接。
- 网站改版后选择器可能失效；可以编辑规则或重新点选。多个脚本同时拦截链接时，建议只保留一个。

## 7. X 阅读器

### 7.1 使用前提

- 在 `x.com` 或 `twitter.com` 页面内使用，并保持 X 登录状态。
- X 阅读器通过当前页面已登录的会话读取帖子数据，不要求你另外登录；脚本不会把密码或登录令牌写入本地存储。
- 如果页面提示「X 网络层未安装，请刷新 X 页面后重试。」，刷新当前 X 页面后再试。

> 从其他网站点击 X 链接时，脚本无法使用 X 阅读器（它依赖 X 页面自身的网络环境），只能按普通网页方式加载；建议直接在新标签页打开，或先进入 X 页面再点击帖子。

### 7.2 打开帖子

- 在 X 的时间线、列表、个人主页等非详情页，点击任意帖子的正文区域，会在弹窗中打开该帖子的阅读器。
- 点赞、转推、收藏按钮，输入框，视频和图片等交互区域不会被拦截。
- 点击帖子中的**引用帖卡片**时，会优先打开被引用的那条帖子；在帖子详情页也一样。
- 帖子详情页的其它区域保留 X 原生交互，不会打开弹窗。

### 7.3 阅读器布局

- **双栏布局：** 左栏显示原帖（如果是从回复中打开，还会显示上方的对话上下文链），右栏显示回复列表。两栏各自独立滚动。
- **单栏布局：** 当弹窗内容区宽度小于 640 像素时，自动切换为上下堆叠：帖子 → 工具行 → 回复框 → 回复。
- 弹窗可以自由缩放；拖动改变宽度后，阅读器会自动在双栏/单栏之间切换。

### 7.4 回复列表与加载更多

- 右栏顶部显示「回复 N」，其中 N 取 X 给出的回复总数和已加载条数中较大的值。
- 回复排序提供三种模式：**相关**（默认）、**最新**、**最多喜欢**。排序只作用于已经加载的回复，不会重新请求全部回复。
- 滚动到接近底部时会自动加载下一页：
  - 加载中显示「正在加载更多回复…」。
  - 加载失败显示「加载失败 · 重试」，点击按钮重试。
  - 全部加载完显示「已显示全部 N 条」。
- 每条评论的时间右侧有回复图标和数量入口，点击会打开这条评论自己的「小巧评论卡」；卡片内可刷新、在 X 打开，按 `Esc`、点击卡片外部或滚动列表会关闭卡片。

### 7.5 点赞、转推、收藏与回复

| 操作 | 行为 |
| --- | --- |
| 回复 | 点击后将回复框定位到这条帖子（评论）或主帖，输入框获得焦点 |
| 转推 | 切换转推状态，计数同步更新 |
| 喜欢（点赞） | 切换喜欢状态，计数同步更新 |
| 收藏 | 切换收藏状态，计数同步更新 |
| 复制链接 | 复制该帖子的 X 链接到剪贴板 |
| 查看 | 只读显示浏览数，不可点击 |

- 互动采用「先更新界面、失败再回滚」的方式：网络请求失败时会恢复原状态，并在阅读器内显示错误提示。
- 需要互动的帖子必须来自 X 的真实数据；极少数尚未同步完成的临时回复会提示稍后再试。

**回复框：**

- 在右栏回复框输入纯文字内容；输入框会随内容自动增高，最多约 200 像素。
- 点击「回复」按钮或按 `Ctrl + Enter`（macOS 为 `Cmd + Enter`）发布。
- 点击某条评论的「回复」会显示「回复 @某人」，可点 ✕ 取消定向回复。
- 发布成功后，新回复会显示在列表最前，并清除草稿。

### 7.6 翻译

- 符合翻译条件的帖子正文会自动翻译，并在正文上方显示「正在翻译…」；翻译完成后显示「翻译自（源语言）」。
- 点击「显示原文」可切换回原文；再点击「显示翻译」可切回译文。
- 翻译失败会显示「重试翻译」，点击可重新请求。
- 翻译默认自动显示，目前没有全局关闭自动翻译的设置项；可在单条帖子上切换「显示原文 / 显示翻译」。
- 译文按普通文本显示，不保留原文中的链接、@提及等富文本格式；需要点击链接时请切换到原文。

### 7.7 回复草稿

- 在回复框输入内容后会自动保存草稿，按主帖分别记录。
- 关闭弹窗、刷新页面、关闭标签页后重新打开该帖子，草稿会恢复；如果之前选择了「回复 @某人」，回复目标也会一并恢复。
- 草稿最多保存 20 条，保留 7 天；发送成功后自动清除对应草稿。
- 回复正文为空时不会保存草稿。

### 7.8 图片与灯箱

- 帖子中的图片会以网格或轮播显示；多图且全部为图片时，默认就是可左右滑动的轮播。
- 点击图片会打开覆盖式大图灯箱，支持缩放和平移：

| 操作 | 效果 |
| --- | --- |
| 拖动底部百分比滑杆 | 百分比以原图为基准：左端是当前适配比例，右端 100% 即原图 1:1 |
| 在滑杆或图片上滚动滚轮 | 每格约 ±8%，按住 `Shift` 可加速到约 ±20%；滑杆以画面中心缩放，图片以光标位置缩放 |
| 双击图片 | 在「适应窗口」与「原图 100%」之间切换 |
| 双指捏合 | 以两指中点为中心连续缩放（触屏） |
| `+` / `-` / `0` 键 | 放大 / 缩小 25%（相对原图）/ 回到适应窗口 |
| 底部 `−` / `+` / `适应` 按钮 | 步进 25%（相对原图）/ 放大 / 回到适应窗口 |
| 放大后单指或鼠标左键拖动 | 平移图片；回到适应比例后拖动恢复为切换图片 |
| 左右方向键 | 切换上一张 / 下一张 |
| `Esc` | 关闭灯箱（优先关闭灯箱，不会直接关闭弹窗） |

- 灯箱直接加载帖子的媒体地址（`media_url_https` 直连，不改写任何参数）；底部百分比以实际加载的图片为 100%：打开时显示当前适配比例，放大到 100% 就是该图 1:1 像素，全程不会插值发糊，也不会超过该图。
- 切换图片后，百分比按当前图片的原图尺寸重新计算。
- 灯箱的左右箭头位于图片外侧；窄屏（视口小于 360 像素或灯箱小于 520 像素）时退化为贴边的半透明小按钮。
- 单张图片也会显示缩放条；切换图片或关闭灯箱时，缩放和平移会重置。
- 灯箱顶部的「在 X 打开」可以在新标签页查看原图页面。

### 7.9 引用帖、长文与作者资料卡

- **引用帖：** 在弹窗阅读器内，引用帖以紧凑卡片显示（作者、正文摘要、右侧缩略图）。点击卡片会在新标签页打开被引用的帖子；卡片内的 @提及和链接仍可单独点击。
- **长文（Article）：** 原帖是 X 长文时，阅读器会显示封面、标题和排版后的正文，并提供「在 X 阅读全文」入口。正文被 X 截断时会出现「显示更多」，点击可补全全文。
- **作者资料卡：** 鼠标悬停在头像、昵称或 @handle 上约 1 秒会弹出资料卡；可在卡片内关注/取关作者。取关需要二次确认；关注状态未确认时按钮会显示「查看状态」，点击会打开 X 个人资料页核对。

### 7.10 主题

- X 阅读器内部的颜色和字体会跟随 X 当前的主题（亮色、微暗、熄灯）自动变化；无法读取 X 样式时会回退到 X 官方主题的固定配色。
- 弹窗外壳（标题栏、工具栏等）仍按设置 → 通用 →「外观主题」显示，两者互不冲突。

### 7.11 已知限制

- X 阅读器依赖 X 的内部接口和当前登录会话；X 改版后可能暂时失效，此时可点击「在 X 打开」查看原帖。
- 翻译使用 X 提供的翻译能力，不是本地翻译；需要保持登录和网络畅通。
- 回复排序只对已加载的回复生效；「相关」顺序由 X 接口返回。
- X 的帖子详情页保留原生交互，脚本只接管引用帖卡片；这是为了避免与 X 自身的点击行为冲突。
- 互动操作（点赞、转推、收藏、回复、关注）会真实作用于你的 X 账号，请谨慎操作。

## 8. 移动端与触屏

### 8.1 支持的移动浏览器

- **Android：** Firefox、Kiwi Browser 等支持 Tampermonkey 的浏览器。
- **iPhone / iPad：** Safari + Userscripts 或 Tampermonkey 扩展。

### 8.2 触屏操作

- 按钮热区最小约 44 像素，方便手指点击。
- 移动端弹窗头部为两行：第一行标题，第二行工具栏按钮；标题不会被按钮挤压。
- 小屏设备（触屏且视口宽或高不超过 560 像素）打开弹窗时，默认铺满接近整个屏幕。
- 拖动标题栏移动窗体；在「移动端」设置中开启「四角缩放把手」后，可拖动四角调整大小。
- 点选链接时，滑动页面是滚动，不会被误判为选中；只有点按才会选中元素。
- X 图片灯箱支持双指捏合缩放、双击 100% / 200% 切换和放大后拖动平移。

### 8.3 移动端设置面板

- 在手机或窄屏上，设置面板会变为贴住屏幕底部的全宽面板，最高约 85% 屏幕高度，并适配安全区。
- 设置面板内部可以正常滚动；「通用 / 移动端 / 最近」标签切换时保持贴底。

### 8.4 手机模式与移动端 UA

- 手机模式（窗体大小 = 手机）主要让弹窗以手机屏幕比例显示；可选 iPhone、Max、安卓、小屏四种尺寸。
- 该模式会为抓取类加载携带对应的移动端 User-Agent，让网站返回移动版页面。
- 直接 iframe 加载的站点无法被脚本修改 User-Agent，此时手机模式只改变窗体尺寸，不改变页面返回的内容版本。

## 10. 常见问题与故障排查

### 10.1 点击链接没有反应

按顺序检查：

1. **脚本是否已安装并启用**：打开 Tampermonkey 管理面板，确认「页内弹窗打开新帖」已启用，版本号为 2.3.7。
2. **页面是否已刷新**：安装或更新脚本后，需要刷新页面才会生效。
3. **站点是否受支持**：确认当前站点在内置列表内（见 [1.2 支持的站点](#12-支持的站点)），或已为当前站点添加链接规则。
4. **「页面链接拦截」是否关闭**：设置 → 通用 → 检查该开关；关闭后所有链接都会按网站原本方式打开。
5. **点击的链接是否可被识别**：内置适配器只识别帖子/文章标题类链接；普通导航、按钮、图片、视频控件不会被拦截。
6. **是否使用了修饰键**：按住 `Ctrl` / `Cmd` / `Shift` / `Alt` 点击、或使用鼠标中键时，脚本会把操作交还给浏览器（例如新标签页打开），这是正常行为。
7. **右下角齿轮是否被隐藏**：如果看不到齿轮，使用油猴菜单「打开设置」或「显示/隐藏右下角设置按钮（本站）」。
8. **是否有其他脚本冲突**：暂时停用其它链接拦截/弹窗类脚本后再试（见 [10.6](#106-与其他脚本冲突)）。

### 10.2 弹窗空白、一直转圈或加载失败

弹窗会针对不同错误显示说明页：

| 提示 | 含义 | 建议 |
| --- | --- | --- |
| 加载超时或被阻止（显示为「加载超时」，并提示在新标签页打开） | iframe 在 15 秒内没有完成加载，或目标站点拒绝被嵌入 | 点击「在新标签页打开」；这是部分站点（尤其是设置了嵌入限制的论坛和社交站）的框架策略限制 |
| 加载超时 / 请求超时 | 请求超时，网络较慢或网站没有响应（抓取页面时的底层提示为「请求超时」） | 点击「重试」；仍失败时在新标签页打开 |
| 网络请求失败 | 网络连接或跨域请求失败 | 检查网络；确认脚本管理器允许跨域访问 |
| 帖子不存在或已被删除 | 服务器返回 404 / 410 | 无需重试，帖子可能已删除 |
| 没有权限查看 | 服务器返回 401 / 403，可能需要登录 | 登录对应站点，或在新标签页打开 |
| 请求太频繁 | 服务器返回 429 | 稍等片刻后重试 |
| 网站暂时出错 | 服务器返回 5xx | 稍后重试 |
| 内容无法显示 | 页面结构无法解析 | 在新标签页打开原页面 |

其他排查方法：

- 加载超过 3 秒时，加载页会提示「还在加载，网站响应较慢」，并提供「在新标签页打开」按钮，不必一直等待。
- 某些站点禁止被嵌入 iframe（例如设置了 `X-Frame-Options` 或 CSP），弹窗最终会显示超时错误，这是站点限制，不是脚本故障。
- 如果弹窗内容空白但页面已显示，可先尝试刷新；仍不行时使用「在新标签页打开」。
- 如果所有站点都无法加载，检查浏览器扩展是否限制了用户脚本的网络权限，或尝试在脚本管理器中重新授权。

### 10.3 图片不显示或显示不全

- 脚本会自动识别常见懒加载图片属性（如 `data-original`、`data-src`、`srcset`、Discuz 的 `zoomfile` / `file` 等），并把占位图替换成真实地址。
- 如果图片仍不显示，可能是目标站点开启了防盗链、需要登录，或图片本身已被删除。点击「在新标签页打开」查看原页面即可确认。
- X 帖子中的图片可以点击打开灯箱；若某张图在灯箱中也无法显示，使用灯箱右上角的「在 X 打开」。
- 网页中的视频、Canvas 动画等富媒体内容在「抓取净化」模式下可能无法完整显示，这是出于安全考虑的正常限制；需要完整功能时请使用「在新标签页打开」或该站点对应的 iframe 加载策略。

### 10.4 设置不保存或不生效

- **确认作用域**：标有「仅本站」的设置只影响当前域名；换一个网站后需要重新设置。主题、在 iframe 中运行、惯用手、四角缩放把手是全局设置。
- **确认是否点击了「恢复默认」**：恢复默认会重置全局设置和当前站点设置。
- **检查浏览器隐私模式**：无痕/隐私模式可能限制 `localStorage`，脚本会退回内存状态，刷新后设置可能丢失。
- **检查脚本存储权限**：如果脚本管理器禁用了 GM 存储，设置无法持久化；请在管理器中允许存储，或退出无痕模式后重试。
- **是否安装了多个副本**：同一脚本安装多份时，可能打开的是旧副本的设置；删除重复安装后只保留一份。

### 10.5 X 阅读器不工作

| 现象 / 提示 | 可能原因 | 处理 |
| --- | --- | --- |
| 提示「X 网络层未安装，请刷新 X 页面后重试。」 | 页面加载时网络层没有成功安装，或刷新前脚本刚更新 | 刷新 X 页面后重新点击帖子 |
| 提示「无法从链接解析出 X 帖子 ID。」 | 链接不是标准的帖子地址 | 使用帖子本身的链接，或直接点帖子正文 |
| 提示「X 返回了数据，但没有找到这条原帖。」 | X 接口返回异常、帖子被删除或受保护 | 在 X 中确认帖子是否可见；点击「在 X 打开」 |
| 阅读器空白或显示「加载失败」 | 未登录 X、接口改版、网络被拦截 | 确认已登录 X；刷新页面；更新脚本；在新标签页打开 |
| 点击帖子没有反应 | 当前在帖子详情页 | 详情页保留 X 原生交互，只有引用帖卡片会弹窗；返回时间线或主页再试 |

补充说明：

- X 阅读器需要 X 页面的 `unsafeWindow` 和当前登录会话；如果你使用的是会隔离页面环境的脚本管理器，可能无法工作，可尝试 Tampermonkey 或更新脚本管理器。
- X 改版后内部接口可能变化，脚本会尽量兼容；遇到无法加载时，优先使用「在 X 打开」。
- 如果 X 页面本身无法正常加载帖子，脚本也无法读取数据，请先确认 X 网页版正常。

### 10.6 与其他脚本冲突

- 同时安装多个「链接拦截 / 弹窗预览」脚本时，可能会重复拦截同一链接、出现多个右下角按钮，或互相覆盖样式。建议只保留一个同类脚本。
- 若页面出现两套弹窗或按钮，检查是否安装了两份 Popup Viewer V2。
- 某些站点脚本会修改页面 DOM 或阻止事件冒泡，可能导致点击无法被识别；临时停用其它脚本排查。
- 浏览器扩展（广告拦截、隐私保护）也可能拦截脚本的跨域请求；可将本脚本或目标站点加入白名单。

### 10.7 使用调试标记

排查问题时可以开启「调试标记」：

1. 打开设置 → 通用 → 高级 →「调试标记」，开启后**刷新页面**生效。
2. 或在地址栏的 URL 后加上 `?pv2_debug`（例如 `https://example.com/?pv2_debug`），刷新页面即可临时启用。
3. 开启后页面上会出现以下标记：
   - 左上角**紫色**标记：脚本启动版本（如 `[PV2] boot v2.3.7`）。
   - 页面右侧深色序号：模块加载顺序，用于定位模块级崩溃。
   - 左上角**橙色**标记：初始化状态（如 `init ok`、`skipped: iframe`）。
   - 左上角**红色**标记：错误信息和错误堆栈摘要。
4. 在 X 页面开启调试后，还可以在浏览器控制台使用 `window.__PV2_X__` 进行自检（如 `__PV2_X__.probe('帖子ID')`、`__PV2_X__.styleDiag()`、`__PV2_X__.postDiag()`）。这些入口仅在调试模式下暴露。
5. 排查完成后请关闭「调试标记」并刷新页面，避免标记影响正常阅读。

> 调试标记默认完全关闭，不会在普通页面上显示任何内容。

### 10.8 提交问题前请准备

在提交 Issue 前，请尽量收集以下信息，能显著加快定位：

- 脚本版本（Tampermonkey 管理面板显示的版本号）。
- 浏览器及版本、用户脚本管理器及版本、操作系统。
- 出问题的站点域名和具体页面 URL（可隐去隐私部分）。
- 复现步骤：点击了什么、期望看到什么、实际看到什么。
- 截图或录屏（包括弹窗的错误提示、右下角齿轮状态）。
- 调试标记截图或控制台报错文本（见 [10.7](#107-使用调试标记)）。
- 是否同时安装了其它链接拦截类脚本。

## 11. 数据与隐私

### 11.1 数据存放在哪里

脚本没有自有服务器，不上传、不收集你的浏览数据。所有数据都保存在浏览器本地的用户脚本存储中；无 GM 存储环境时回退到 `localStorage`（键名前缀为 `popup-viewer:`）。

| 存储键 | 内容 | 说明 |
| --- | --- | --- |
| `pv2:settings` | 全局设置 | 主题、在 iframe 中运行、惯用手、四角缩放把手等 |
| `pv2:siteSettings` | 各站点设置 | 按域名保存的窗体大小、驻留方式、滚动条、锁定等 |
| `pv2:rules` | 链接规则 | 按域名保存的选择器和启用状态 |
| `pv2:history` | 最近打开记录 | 最多 100 条，设置「最近」页只显示当前站点最近 20 条 |
| `pv2:debug` | 调试标记开关 | 独立存储，不随「恢复默认」清除 |
| `pv2:xDrafts` | X 回复草稿 | 最多 20 条，保留 7 天，发送成功后清除 |

### 11.2 脚本会访问哪些网络资源

- 脚本头部声明了 `@connect *`，表示允许通过用户脚本管理器的跨域请求能力访问任意站点。这是因为脚本支持任意网站的链接规则，无法预先枚举所有目标域名。
- 脚本通过 `@include *://*/*` 在所有网站运行，目的是支持任意网站的链接规则；未命中适配器或规则时，脚本不会创建弹窗或抓取页面内容。
- 实际请求只发生在你点击链接、或鼠标悬停在可能命中的链接上触发预热时；脚本不会在后台扫描或上传你的浏览记录。
- 脚本通过 `GM_xmlhttpRequest` 请求目标页面 HTML（抓取类加载）；图片、视频等资源由浏览器按原页面地址直接加载。
- 脚本不包含统计、广告、远程配置或任何第三方上报代码。

### 11.3 X 账号与内容

- X 阅读器通过当前 X 页面已登录的会话读取帖子数据，使用页面自身的登录态；脚本不会保存你的密码或登录令牌，但会在页面内存中读取 X 已有的登录凭据（如 `ct0` Cookie 和请求头中的授权信息），仅用于向 X 发起请求。
- 点赞、转推、收藏、回复、关注等操作会通过 X 的接口真实作用于你的账号，和你在 X 网页上手动操作效果相同。
- 翻译请求会发送到 X 的翻译服务，内容范围仅限需要翻译的帖子正文。
- 你的 X 数据仍受 X 的隐私政策约束，本脚本不额外存储帖子内容（回复草稿除外，且仅保存在本地）。

### 11.4 如何清除数据

| 想清除的内容 | 操作 |
| --- | --- |
| 当前站点的最近记录 | 设置 → 最近 →「清空本站」，二次确认 |
| 当前站点和全局设置 | 设置 → 底部「恢复默认」，二次确认 |
| 所有站点的最近记录 / 设置 / 规则 | 在 Tampermonkey 的脚本存储页面清空，或删除脚本后重新安装 |
| 某一条链接规则 | 链接规则面板中删除该条（删除后 4 秒内可撤销） |
| X 回复草稿 | 发送成功后自动清除；也可在脚本存储中清除 `pv2:xDrafts` |

### 11.5 安全建议

- 只从项目官方仓库或可信来源下载 `dist/popup-viewer-v2.user.js`，不要安装来源不明的修改版。
- 安装时留意脚本管理器展示的权限：本脚本需要 `GM_xmlhttpRequest`、`GM_addStyle`、`GM_getValue`、`GM_setValue`、`GM_registerMenuCommand`、`unsafeWindow`，以及 `@connect *` 跨域权限。
- 在公共电脑上使用后，按 [11.4](#114-如何清除数据) 清除本地数据，或直接删除脚本。
- 对于需要登录的敏感站点，若弹窗显示异常，优先使用「在新标签页打开」，不要在弹窗内输入敏感信息。
