# 文档索引

本目录收录 Popup Viewer V2 的用户文档与开发文档，当前版本为 **2.3.7**。文档以简体中文为主；如与最新实现不一致，请以源码为准。

## 目录结构

- `user-guide.md`：面向普通用户的安装、设置、操作与故障排查手册
- `development.md`：面向贡献者与维护者的构建、架构、扩展开发与发布手册
- `README.md`：本索引（仓库根目录的社区文件与变更记录不在本目录内）

## 文档维护约定

- 新增、移动或删除文档时，请同步更新本索引，避免出现死链。
- 文档中的命令、路径、版本号必须与仓库实际内容一致；不要保留占位符或待办事项。
- 用户可见功能变化时，同步更新[用户使用手册](user-guide.md)、[README](../README.md) 与 [CHANGELOG](../CHANGELOG.md)。
- 开发流程、构建方式或架构变化时，同步更新[开发手册](development.md)。
- 安全漏洞请不要在公开 Issue 或文档中讨论，请按[安全策略](../SECURITY.md)私下报告。
