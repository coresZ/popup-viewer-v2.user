# Chapter 4: 威科夫价格周期与三大定律

## Core Idea
威科夫用三条定律解释价格为什么动、能动多远、什么时候会变：**供需决定方向，因果决定幅度，量价不协调提前预警转折**。

## Frameworks Introduced
- **定律一 · 供需原理（决定价格方向）**：供小于求 → 价格上涨；供大于求 → 价格下跌。用法：在 K 线图上读"价格与成交量的关系"来判断供需，而不是看单一指标。
  - 原文提示：这条定律"听起来很简单，但需要花费很长时间练习才能精准把握量价关系"。
- **定律二 · 因果原理（决定未来涨跌幅度）**：通过计算横盘整理区间的筹码，推算未来行情大小；用点数图分析原因与结果。**"因"=点数图水平区间的点数；"果"=由这些点造成的股价上下波动**。用法：建仓前先用点数图算出目标空间（见 Ch11）。
- **定律三 · 量价不协调原理（提前预警趋势变化）**：成交量与股价不协调，常常是趋势改变的信号。典型：**连续放量，但股价涨幅越来越小 → 庄家正在出货**。用法：把它当作"努力与结果背离"的早期警报。
- **理想价格周期**：市场准备上升（markup）前买入、下跌（markdown）前卖出。原文强调这只是**理想状态**，现实交易要复杂得多。

## Key Concepts
- **供需原理**：价格方向的唯一决定因素。
- **因果原理**：区间横向计数 → 未来纵向幅度。
- **量价不协调**：量增价滞（或价增量缩）的背离现象。
- **markup / markdown**：上升段 / 下跌段。
- **横盘整理区间（trading range）**：因果计数发生的地方，也是吸筹/派发判断的舞台。
- **时间**：与价格、成交量并列的第三个分析维度（"研究价格行为、成交量和时间"）。

## Mental Models
- **方向—幅度—转折三问**：往哪走（供需）？能走多远（因果）？要变了吗（量价不协调）？
- **把成交量当"努力"，价格当"结果"**：两者协调=趋势健康；背离=趋势可疑（详见 Ch9）。
- **区间是"因"的容器**：区间越宽、时间越长，累积的"因"越大。

## Anti-patterns
- **只用供需定律**：没有因果计数就不知道盈亏比是否值得（五步法步骤 3 会因此落空）。
- **看到放量就追**：连续放量但涨幅收窄正是出货特征，属于典型的量价不协调陷阱。
- **把理想周期当现实路径**：原文明确说现实比"上升前买、下跌前卖"复杂得多。

## Worked Example
原文给出的三个定律并列示例（同一张图上可同时读到）：
- 供需原理："当供小于求时，价格就会上涨；当供大于求时，价格就会下跌。交易者可以通过 K 线图上面的价格和成交量的关系来分析供需关系。"
- 因果原理："通过计算横盘整理区间的筹码计算未来行情的大小。可以用点数图来分析原因并预测结果。"
- 量价不协调原理："比如说连续放量的情况下股价的涨幅越来越小。这个现象说明庄家正在出货。"

## Key Takeaways
1. 三条定律各有分工：**方向 / 幅度 / 转折**，不可互相替代。
2. 供需判断依赖"价格 + 成交量"的联合阅读，需要长期练习。
3. 因果计数是**建仓前的许可条件**（目标空间够不够）。
4. 量价不协调是**最早的预警**，通常早于形态破坏。
5. 时间是与价格、成交量并列的分析维度。
