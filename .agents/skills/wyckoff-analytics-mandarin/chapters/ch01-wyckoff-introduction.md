# Chapter 1: 威科夫介绍（Richard Wyckoff 与方法的由来）

## Core Idea
理查德·威科夫（1873–1934）从报价员做起，通过采访并总结当时最顶尖交易者的手法，形成了一套"识别主力吸筹与派发"的完整方法论——它的目的不是预测价格，而是**读懂大资金正在做什么**。

## Frameworks Introduced
- **技术分析五大巨人**：威科夫与道琼斯、甘恩、埃利奥特、美林并列。定位用：当你需要判断一套技术分析体系的谱系与侧重时，威科夫的独特之处是"以主力行为为研究对象"，而非形态或周期。
- **从盘口到理论的三段式**：报价员（看真实成交）→ 记者/编辑（采访大师并归纳）→ 教育者（把规则教给散户）。用法：理解威科夫结论为何强调"成交量与价差"，因为它们的源头是场内实际成交观察。

## Key Concepts
- **威科夫（Richard Wyckoff）**：20 世纪初股票市场技术分析先驱，活跃于纽约经纪与出版业。
- **报价员（quote boy）**：15 岁起的起点岗位，直接接触报价与成交流。
- **《华尔街杂志》**：威科夫出资发行并任编辑与作者近 20 年，鼎盛订阅量约 20 万份。
- **股票市场学院（Stock Market Institute）**：1930 年建立（后称），课程核心是识别主力收集筹码与派发筹码的过程。
- **鲍勃·伊万斯（Bob Evans）**：威科夫去世后发展并推广其课程的学生。
- **综合人（composite man）**：威科夫对"市场主力"的人格化称呼（见 Ch3）。

## Mental Models
- **把威科夫当成"行为观察者"而非"指标发明者"**：他给的是一套读图与读量的流程，不是一组参数。
- **散户失败的原因被归为"不懂游戏规则"**：因此方法的目标是让你站到规则制定者那一侧。

## Anti-patterns
- **把威科夫当形态学**：只找"看起来像 Spring 的形状"，而不追问成交量与价差是否支持主力吸筹——这丢掉了方法的核心。
- **忽略其出版与教育背景**：不理解"规则/心理"取向，就会误以为它是一套纯技术指标。

## Worked Example
威科夫的成长路径本身就是方法的样本：15 岁做报价员 → 二十多岁自营公司 → 办刊近 20 年并采访摩根大通、杰西·利弗莫尔等大师 → 归纳出"技术分析 + 交易心理"的全套理论 → 1930 年办学，专门讲"如何识别庄家收集与派发筹码" → 1934 年去世后由伊万斯继续推广。**每一步都在把"场内观察"转成"可教规则"**，这就是为什么他的框架总是围绕"主力在做什么、证据是什么"。

## Key Takeaways
1. 威科夫方法的研究对象是**主力行为**，不是价格形态本身。
2. 它的原始素材来自真实成交观察与大师访谈，因此成交量/价差是核心证据。
3. 方法被设计成**可教、可练**的流程，而非直觉。
4. 直到今天，专业交易者与机构仍在应用；散户反而用得少。
5. 学习它的正当目标是"识别主力吸筹与派发"，不是找神奇指标。
