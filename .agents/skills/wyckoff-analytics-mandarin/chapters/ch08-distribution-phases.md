# Chapter 8: 派发的阶段 A–E

## Core Idea
派发五阶段是吸筹五阶段的镜像：**A 涨势停止、B 清仓建空、C 测试需求、D 供应主导、E 下跌展开**。核心判据始终是"需求是否还能把价格推回前高"。

## Frameworks Introduced
- **派发五阶段模型**：与吸筹共用"阶段"语言，但方向相反。用法：判断"主力派发到哪一步"，决定是观望、做空还是加空。
- **再派发（re-distribution）识别法**：下跌趋势中会暂时出现下跌停止，形成**再次派发筹码的区间**；其阶段 A 与吸筹区间相像（如卖盘密集区出现的价格与成交量），而**阶段 B–E 可用分析市场顶端派发区间的方法来分析**。
- **阶段 C 的两种形态**：**上冲回落**或**派发后上冲回落（UTAD）**。判据：价格涨到区间顶部阻力区之上，然后迅速回到并收市于区间内 → 这是对剩余需求的测试，也是"牛市"陷阱。

## Key Concepts
- **阶段 A（涨势停止）**：此前需求一直主导市场；此阶段 **PSY 与 BC 首次预示供应开始进入市场**。紧接这两个事件发生的，经常是**自然回落与对 BC 的二次测试**；大多数情况下 AR 与 ST 的成交量显著减低。**上升趋势也可以在没有高潮行为的情况下终结**：此时市场呈需求耗尽特征——价差缩短、成交量减少、上升幅度比巨量供应出现前减少。
- **阶段 B（清仓建空）**：为新的下降趋势做准备。机构与主力开始清仓并建立空头，准备迎接下跌。派发 B 与吸筹 B 相似，区别是**主力目标是在区间内派发，并尽可能消耗残余的做多力量**；此过程可见供需平衡已向供应倾斜（如 SOW 常伴随下降过程中价差扩大与成交量显著增加）。
- **阶段 C（测试需求）**：可能以上冲回落或 UTAD 形式出现。它使主力误导公众，并在突破后下跌前在高价位把股票卖给公众；也可逼迫早期做空者高价补仓。**通常派发区间需求虚弱，价格无法再次达到 BC 与最早 ST 的水平** → 此时 C 阶段对需求的测试表现为**区间内次级高点的上冲回落**。
- **阶段 D（供应主导）**：C 的测试过后，D 展示最后一波需求。价格向区间支撑区下跌、甚至突破支撑。**UTAD 后跌破支撑，或跌下交易区间中线 → 显示供应主导市场**。D 阶段经常有多个小幅上升波段被标记为 **LPSY** → 是做空、或盈利加空的好机会。**任何在阶段 D 仍然做多的人都是自找麻烦**。
- **阶段 E（下跌展开）**：股票离开交易区间，供应主导市场。在重要的 SOW 出现、调整区间被跌破之后，市场价格经常上升到支撑线附近、**回踩支撑跌破的位置** → 这也是高胜算的做空点。熊市中的上升经常脆弱无力；做空者可随股价下跌**移动止损点**保护利润。大幅下跌过后，高潮行动可能显示再派发区间或吸筹的开始。

## Mental Models
- **"需求能否回到前高"是分水岭**：做不到 → 供应主导，进入 D。
- **反弹的质地决定性质**：熊市中的上升"脆弱无力"，与吸筹阶段的放量 SOS 形成对比。
- **回踩跌破位=做空点**：E 阶段价格回到支撑线附近时，是低风险做空位置。
- **止损跟着趋势移动**：下跌趋势中不断下移止损以保护利润。

## Anti-patterns
- **在阶段 D 做多**：原文直白："任何在阶段 D 仍然做多的人都是自找麻烦。"
- **把无高潮的涨势结束当"没问题"**：需求耗尽型终结同样有效，特征是价差缩短、量能减少。
- **把再派发当吸筹**：再派发的 A 阶段与吸筹相像，必须结合后续阶段与相对强度区分。
- **在 UTAD 处重仓做空**：庄家反复用上冲回落清洗做空者，应等 D 阶段与 LPSY。

## Worked Example
原文对阶段 C 与 D 的连贯读法：需求虚弱 → 价格无法再次达到 BC 与最早 ST 的水平 → C 阶段的测试表现为区间内次级高点的上冲回落 → 测试过后 D 展示最后一波需求，价格向支撑区下跌甚至突破 → UTAD 后跌破支撑或跌下区间中线，确认供应主导 → D 阶段出现多个小幅上升波段，标记为 LPSY → 这些 LPSY 是做空或加空的机会。操作纪律上：激进者可在 UTAD 后做空（风险/回报有利），但更安全的是等 D 阶段与 LPSY。

## Key Takeaways
1. 派发五阶段与吸筹镜像：**A 停涨、B 建空、C 试需求、D 供应主导、E 下跌**。
2. **PSY + BC 是供应进入市场的首个信号**，随后常是 AR 与 ST。
3. 涨势也可在**无高潮**下终结（需求耗尽：价差缩短、量减、涨幅变小）。
4. **需求回不到前高**是进入阶段 D 的关键证据。
5. **LPSY 是做空/加空点**；D 阶段做多等于自找麻烦。
6. E 阶段回踩跌破的支撑线是**高胜算做空点**，止损随趋势下移。
