# Chapter 7: 派发中的事件标注

## Core Idea
派发是吸筹的镜像：主力在高位把筹码交给公众。按**阶段归属**的时间顺序是 **PSY → BC → AR → ST → SOW →（UTAD）→ LPSY**（SOW 在阶段 B、UTAD 在阶段 C、LPSY 在阶段 D），其中 **SOW 与 LPSY 是性质改变与需求枯竭的确认**。

> 注：源文档的事件清单按"PSY、BC、AR、ST、SOW、LPSY、UTAD"排列，但正文的阶段描述把 UTAD 明确放在**阶段 C**、LPSY 放在**阶段 D**，故此处按阶段先后给出时间顺序。

## Frameworks Introduced
- **派发事件序列（按阶段）**：PSY → BC → AR → ST → SOW →（UTAD）→ LPSY。用法：与吸筹序列对照记忆——BC 对 SC、UTAD 对 Spring、SOW 对 SOS、LPSY 对 LPS；但**不能按源文档的清单顺序当作时间顺序**。
- **镜像对照法**：
  - **PSY ↔ PS**（初始供应 ↔ 初始支撑）
  - **BC ↔ SC**（购买高潮 ↔ 抛售高潮）
  - **AR ↔ AR**（自然回落 ↔ 自动反弹）
  - **ST ↔ ST**（二次测试，方向相反）
  - **UTAD ↔ Spring/Shakeout**（向上洗盘 ↔ 向下洗盘）
  - **SOW ↔ SOS**（弱势信号 ↔ 强势信号）
  - **LPSY ↔ LPS**（最后供应点 ↔ 最后支撑点）
- **阻力区的确认法**：**前面的 BC 或其他二次测试代表阻力区**；价格移动到阻力区之上后迅速反转、收盘于阻力区之下，即上冲回落；**上冲回落之后价格经常回测交易区间的底部**。

## Key Concepts
- **PSY 初始供应**：价格大幅上升后主力开始大量派发的位置；成交量扩大、价格振幅加宽 → 显示趋势改变即将到来。
- **BC 购买高潮（买入密集区）**：成交量与价格振幅都显著增大，购买力达到高潮；在股市顶端，公众紧急的大量买单都被主力的卖单满足；**经常在发布利好消息时出现，机构借机出货给散户**。
- **AR 自然回落**：BC 之后买盘急剧下降，但卖盘的高量供应仍持续 → 自然回落；**这次抛售的低点有助于界定派发交易区间的下缘**。
- **ST 二次测试**：价格再次回到 BC 附近测试供需平衡；若顶端被确认 → 供应高于需求；接近 BC 造成的阻力区时**成交量减少、价差缩短**。ST 可能以**上冲回落**形式出现（价格移到阻力区之上后迅速反转、收于阻力区之下）。
- **SOW 熊市初显（弱势信号）**：价格下降到交易区间底部、甚至稍微突破，常伴随价差与成交量增大。**AR 与 SOW 一起表示股市性质改变：供应开始主导市场**。
- **LPSY 最后供应点**：测试 SOW 处支撑力度后，股价虚弱上升、价差变窄 → 显示上涨困难（可能因需求虚弱、供应巨大，或二者兼有）。**代表需求枯竭，是大机构在股市快速下降前的最后一波派发**。
- **UTAD 派发后上冲回落（向上洗盘）**：与吸筹区间中的 Spring 和终极震仓**相反**；发生在交易区间的后半部分，在突破区间后对新出现的需求做出决定性测试。与 Spring/震仓类似，**它不是结构上的必要因素**（原文派发示意图 1 有 UTAD，示意图 2 没有）。

## Mental Models
- **派发=把"利好"当燃料**：BC 常在利好消息中出现，因为那是最好的出货环境。
- **"上涨困难"就是证据**：LPSY 的价差变窄、涨势虚弱，比价格下跌更早暴露需求枯竭。
- **UTAD 是给多头的陷阱**：它"看似牛市继续"，目的是让做突破的多头犯错。
- **成交量在阻力区萎缩**：ST 时成交量减少、价差缩短 = 供应高于需求的确认。

## Anti-patterns
- **把 UTAD 当突破**：突破区间后迅速收回，是测试剩余需求，不是新趋势启动。
- **忽略 AR 低点的作用**：它界定派发区间下缘，漏掉就会画错框。
- **在 LPSY 处抄底**：最后供应点代表需求枯竭，是"继续下跌"的前奏。
- **假设 UTAD 必然出现**：原文明确它不是结构上的必要因素。

## Worked Example
原文对 UTAD 的完整描述与操作含义：它发生在交易区间后半部分，突破区间后对新出现的需求做决定性测试；它使主力在市场趋势上误导公众，并在**突破后下跌前的高价位把股票卖给公众**；同时可**逼迫早期做空者在高价位补仓**，从而收买主力的高价筹码。操作上：激进交易者可能希望在 UTAD 之后做空，此时风险/回报系数甚为有利；但**庄家反复使用上冲回落让做空者出局，所以等到阶段 D 和最后供应点再做空更为安全**。

## Key Takeaways
1. 派发事件与吸筹事件一一镜像，用对照法记忆最稳。
2. **BC 常在利好中出现**，是机构出货窗口。
3. **AR 低点界定区间下缘**；**BC/ST 构成阻力区**。
4. **SOW 是性质改变（供应主导）的确认**。
5. **LPSY = 需求枯竭**，是快速下跌前的最后一波派发。
6. UTAD 可做空，但**更安全的做空点在阶段 D 与 LPSY**。
