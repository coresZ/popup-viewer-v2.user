# Chapter 13（附录）: 分析工作流 —— 产出完整报告

> **性质说明**：本章不是源文档内容，而是**应用层附录**：把 Ch1–Ch12 的判读框架落成一份可复核的分析报告格式。输出契约吸收自社区版 `wyckoff-method` skill，并按源文档补回了它缺失的**图谱分工**与**组合信号**。

## 用法

对用户给出的股票 / 指数 / 图表，按下面的 6 节模板输出。每一节都必须落到具体证据（图谱、量价、阶段、检验条目），不允许只给结论。

## 输出模板

```markdown
# 威科夫分析报告：[代码 / 名称]

## 1. 大盘环境与趋势判断（五步法第 1 步）
- 指数当前所处阶段与趋势方向（吸筹 / 拉升 / 派发 / 下跌）
- 依据：主要指数的 K 线图 + 点数图读到了什么
- 结论：允许做多 / 允许做空 / 观望

## 2. 个股阶段与事件标注（五步法第 2 步 + Ch5–Ch8）
- 相对强度：强于还是弱于大市（给出比率或对比说明，不靠感觉）
- 当前处于吸筹 / 派发的哪个阶段 A–E，依据是什么
- 已识别事件：吸筹侧 PS/SC/AR/ST/Spring/Shakeout/Test/SOS/LPS/BU；派发侧 PSY/BC/AR/ST/SOW/UTAD/LPSY
- **区间边界**（判断的前提）：吸筹用 SC 最低点 + 成功的 ST + AR 最高点；派发用 AR 低点界定下缘、BC 与其他 ST 构成阻力区 → 给出水平价位
- 量价解读：努力与结果落在三种组合的哪一种（协调 / 供应减低 / 大买家吸收供应）

## 3. 九个检验检查清单（五步法第 4 步）
- 买入侧或卖出侧逐条打分：通过 / 未通过 / 待观察
- **每条必须标注所需图谱**：检验 1、9 = 点数图；检验 7 = 相对强度（K 线图）；其余 = K 线图与/或点数图
- 总体通过率，以及未通过项对结论的影响

## 4. 点数图目标测算（五步法第 3 步 + Ch11）
- 图框尺寸与反转值的选择理由（低价股 0.5–1 点 / >200 美元 5 点 / 道指 100 点）
- 计数起点 LPS，以及向左计数的阶段划分与理由（**说明为何这样分段**）
- 至少两个目标：区间最低值、计数列价位与最低值的**均值**（保守）
- 最高值估计，以及到达后的「停，看，听」观察点

## 5. 交易计划
- 方向（多 / 空 / 观望）
- 入场条件与价位（做多优先 **LPS**；做空优先阶段 D 的 **LPSY** 或回踩跌破的支撑线）
- 止损位置与依据
- 目标价位与盈亏比（**检验 9：目标盈利 ≥ 初始止损的 3 倍**）
- 仓位建议

## 6. 风险与应变
- 大盘反转时的应对（约 **3/4** 股票与大盘同向）
- 关键失效信号（如 Spring 之后没有 SOS、量能不支持、区间被反向突破）
- 说明当前判断的不确定性：**阶段可能重叠或缺失某些事件**，不要硬套
```

## 最高胜率组合信号

| 方向 | 组合 | 依据 |
|---|---|---|
| **做多** | 低量 Spring（阶段 C）→ Test 底部抬高、量能递减 → **SOS 确认** → **LPS 入场** | 源文：低成交量的弹簧效应预示股票已准备拉升，是初步建仓的好时机；SOS 之后缩量小振幅回调到支撑点即 LPS，是买入或加仓机会 (Ch5, Ch6) |
| **做空** | UTAD（阶段 C）→ 跌破支撑或跌下区间中线（进入阶段 D）→ **LPSY 做空** | 源文：UTAD 后跌破支撑或跌下中线显示供应主导市场；D 阶段的 LPSY 是做空或加空的机会，**等 D 与 LPSY 比在 UTAD 处直接做空更安全** (Ch7, Ch8) |

> **顺序提示（注意）**：源文档的事件**清单**按 "PSY、BC、AR、ST、SOW、LPSY、UTAD" 排列，但正文阶段描述把 **SOW 放在阶段 B、UTAD 放在阶段 C、LPSY 放在阶段 D**。因此时间顺序是 `PSY → BC → AR → ST → SOW →（UTAD）→ LPSY`，不要按清单顺序理解。社区版把卖点写成"UTAD + 后续 SOW"，与阶段归属矛盾，本附录按阶段归正。

## 数据不足时的处理

若只有日线数据、拿不到点数图：第 4 节必须明确写"**数据不足、未做点数图计数**"，并说明因此检验 1、9 无法判定；**不要编造目标价**。此时结论应降级为"方向可判、仓位需减"，而不是给出精确目标。

## 三条纪律

1. **始终以综合人视角思考**：对任何量价现象先问"这个走势对谁有利？"（Ch3）
2. **入场点不是确认点**：SOS 是确认、LPS 才是入场；UTAD 是测试、LPSY 才是出场（Ch5–Ch8）
3. **点数图红线**：永不要只看一个阶段所预测的结果；点数图的"阶段"≠ 吸筹/派发的阶段 A–E（Ch11）
