# Chapter 6: 吸筹的阶段 A–E

## Core Idea
把吸筹区间按时间切成五个阶段：**A 止跌、B 建仓、C 测试、D 需求主导、E 离开区间**。阶段判断决定你现在该等、该买、还是该加仓。

## Frameworks Introduced
- **吸筹五阶段模型**：用阶段而非点位来定位"主力做到哪一步"。用法：先判阶段，再决定动作（等测试 / 初步建仓 / 加仓 / 持有）。
- **阶段与事件映射**：A=PS/SC/AR/ST；B=多次测试与向上洗盘（区间内震荡）；C=Spring/震仓及其测试（可能伴随 SOS）；D=SOS + 多次 LPS；E=离开区间、脚踏石式盘整。
- **再吸筹（re-accumulation）的识别法**：上涨过程中的横盘振荡也可是吸筹，但**看不到主要的 PS、SC、ST**；此时阶段 A 看起来更像派发图表的阶段 A，而 B–E 的表现与底部吸筹差不多，**只是时间较短、幅度较小**。

## Key Concepts
- **阶段 A（止跌）**：前期向下趋势停止。卖盘主导 → 枯竭；到 PS/SC 时卖盘快枯竭，振幅与成交量很大，专业人士在底部收集恐慌大众的筹码。卖压减轻 → 自动反弹。若价格再次临近 SC 价位或稍上，而卖盘、振幅、成交量都减少 → 成功的二次测试。若 ST 低于 SC 价位 → 可能创新低或盘整时间延长。**区间范围由 SC 最低点、成功 ST 点、AR 最高点决定**。有时下跌不剧烈，A 阶段的振幅与成交量不会突然放大；一般**更希望看到 PS、SC、AR、ST**，因为它们既提供突出的图谱特征，又表明有大机构主力正在吸纳。
- **阶段 B（建仓）**：为后面行情做准备，属因果原理中的"因"。主力低价建仓、屯筹待涨；建仓时间可能很长（有时一年或更长），包括低价吸筹、高位做空试探。价格在支撑线与阻力线之间波动，**通常有多个测试，也包括向上的洗盘**。早期波动范围大、成交量大；随着专业交易者吸纳浮筹，**区间内下行波段的成交量会降低**；卖盘衰竭 → 进入阶段 C。
- **阶段 C（测试）**：对卖盘做测试，主力借此判断市场是否准备好上涨。市场要么突破区间上涨，要么**向下洗盘**（先破支撑线再上涨）。洗盘=价格跌到支撑线以下又快速回到区间内；跌破支撑意味着下跌趋势"又开始"→ 这是**空头陷阱**，实际终结下跌趋势、把最后的卖家或空头套住。**通过这次下跌创造的最低点与成交量判断卖盘力量**。成功的测试（Spring/震仓）代表高成功率的交易机会；**低成交量的 Spring（或对震仓的低量测试）预示股票已准备拉升 → 初步建仓的好时机**。洗盘之后出现的 SOS 会确认分析。测试不一定有洗盘，也可能发生在支撑线上方 → 此时认出阶段 C 会有困难。
- **阶段 D（需求主导）**：需求成为主趋势。**上涨放量、振幅变大（SOS）；回调缩量且振幅变小（LPS）** → 表明需求大于供应。股价至少会上涨到调整区间的上沿。**LPS 是买入或加仓的好机会**。
- **阶段 E（离开区间）**：股价已离开横盘振荡市场，需求控制市场；回调短暂、不明显。也可能在新高位置形成新的调整区间（有人获利了结、也有机构再次吸筹）→ 称为**"脚踏石"（stepping stone）**，预示股价还会有新高。

## Mental Models
- **阶段=主力的进度条**：A 收集、B 屯筹、C 试探、D 拉升、E 趋势延续。
- **"量缩的回调"是阶段推进的信号**：B 阶段下行波段量能递减、D 阶段 LPS 缩量，都是同一逻辑。
- **C 阶段是分水岭**：能不能在 C 的低量测试处建仓，决定了成本高低。
- **再吸筹"缩水版"**：同样的剧本、更短的时长与更小的幅度。

## Anti-patterns
- **把 A 阶段当买入区**：A 只是止跌，真正的高胜率入场在 C 的低量测试与 D 的 LPS。
- **期待每次都有洗盘**：C 阶段可能不洗盘、测试在支撑线上方，此时"认不出 C"是正常的。
- **把再吸筹当派发**：再吸筹的 A 阶段形似派发 A，必须结合后续 B–E 与相对强度判断。
- **在阶段 D 之后才追**：D 的机会在 LPS 回调，而非 SOS 当天。

## Worked Example
原文对阶段 A 的完整读法：卖盘主导 → 到 PS/SC 卖盘快枯竭（振幅大、成交量大，专业人士收集恐慌筹码）→ 卖压减轻后自动反弹 → 价格再次临近 SC 价位或稍上，若卖盘/振幅/成交量同时减少，即为**成功的二次测试**；若二次测试低于 SC 价位，则可能创新低或盘整延长。由此用 **SC 最低点 + 成功 ST + AR 最高点**画出区间上下边界，后续所有阶段判断都在这个框内进行。原文同时指出：下跌不剧烈时，A 阶段的振幅与成交量可能不会突然放大，但**有 PS/SC/AR/ST 的图谱更可信**，因为它们直接表明大机构在吸纳。

## Key Takeaways
1. 五阶段是**进度条**：A 止跌、B 建仓、C 测试、D 需求主导、E 离开区间。
2. **高胜率买点在 C 的低量测试与 D 的 LPS**，不在 A。
3. B 阶段的关键证据是**下行波段成交量递减**。
4. C 阶段的洗盘是**空头陷阱**，其最低点与成交量衡量卖盘力量。
5. 洗盘与测试都非必然形态；认不出阶段 C 时不要硬套。
6. 再吸筹 = 时间更短、幅度更小的同一剧本。
