# Chapter 9: 供求分析的基本方法与比较强度（努力 vs 结果）

## Core Idea
用**相对强度比**比较个股与大市/指数，再用**"努力（成交量）与结果（价格）"是否协调**判断供应是否被吸收——这是把三大定律落到具体图谱上的操作层。

## Frameworks Introduced
- **比较强度 / 相对强度比（comparative & relative strength）**：现代威科夫派用相对强度比来比较股票与大市或某个指数在各个点位的强弱。**优势**：使用相对强度比更容易消除"股票与指数衡量方法不同"所造成的误差。用法：替代肉眼看"谁涨得多"，直接比较同点位强弱。
- **努力与结果定律（effort vs result）**：成交量=努力，价格变动=结果。用法：在每一次回调/反弹处读两者的协调性，判断供应与需求谁在占优。
  - **协调**：价差增大 + 成交量增加 + 价格下跌 → 供应真实、下跌健康。
  - **结果减弱**：价差变小 + 成交量减少 → 供应量减低 → 可能短暂上扬。
  - **努力增加、结果减少**：跌幅减少但成交量增加 → 众多大买家出现、吸收了供应 → 预计继续上涨。
- **九检验的实证读法**（AAPL 案例）：把 Ch10 的检验逐条落到具体图谱证据上（见下方 Worked Example）。

## Key Concepts
- **相对强度比**：个股与指数的同点位强弱比。
- **努力（effort）**：成交量。
- **结果（result）**：价格变动（幅度/价差）。
- **浮筹被吸收**：区间内成交量逐渐减低 + K 线顶底抬高 → 表明浮筹在被吸收、减少。
- **供应耗尽后的"少量需求"**：虽然需求也减少，但由于供应耗尽，**少量的需求也可以使价格上涨**。
- **次级高点**：派发区间内低于 BC/ST 的反弹高点，用于识别阶段 C 的上冲回落。

## Mental Models
- **"努力必须有结果"**：量增而价不动（或价跌而量减）都是信号，不是噪音。
- **用比率代替感觉**：相对强度比消除量纲差异，比"看起来更强"可靠。
- **三段式读回调**：第一次看是否协调 → 第二次看供应是否减少 → 第三次看是否出现吸收。
- **需求可以很小**：供应耗尽后，价格不需要大量买盘就能上涨。

## Anti-patterns
- **只看价格不看量**：努力与结果定律要求两者并读。
- **把量减一律当利好**：量减在下跌中表示供应减低（利好），在上涨中可能表示需求不足。
- **忽略衡量口径差异**：直接比较个股与指数的涨跌幅而不做比率归一，容易得出错误结论。

## Worked Example
**AAPL 的三次价格回调（努力与结果定律）**：
- **Reaction #1**：价格下跌于数个价差增大、成交量增加的阴线 → **成交量（努力）与价格下跌（结果）和谐一致**。
- **Reaction #2**：回调程度与第一次相仿，但**价差比第一次变小、成交量减少** → 表明供应量减低，**从此推测可能会有一次短暂的价格上扬**。
- **Reaction #3**：价格下跌幅度减少，**但成交量增加** → 努力增加了、结果却减少了 → 说明**众多大买家出现、吸收了供应**，预计股票会继续上涨。

**AAPL 的九检验逐条对应**：下行趋势结束于 **PS、SC、AR、ST** → 满足**检验 2**；区间内成交量逐渐减低、K 线顶底越来越高 → 浮筹被吸收减少，看涨行为 → 满足**检验 3**；下跌趋势与通道被打破、价格在区间内盘整 → 满足**检验 4**；2009 年 2–4 月顶底越来越高 → 满足**检验 5、6、7**；已盘整 6 个月、积蓄足够能量、底部铸成 → 满足**检验 8**。原文特别提醒：**检验 1 与 9 都需要点数图**，其横向计量原则见 Ch11。

## Key Takeaways
1. 比较强度用**比率**，消除个股与指数口径差异。
2. 努力与结果的三种组合对应三种结论：**协调 / 供应减低 / 供应被吸收**。
3. **跌幅缩小 + 量能增加 = 有大买家吸收供应**（看涨）。
4. **供应耗尽后少量需求即可推高价格**。
5. 九检验可以用具体量价证据逐条核对，不是主观印象。
6. 检验 1 与 9 必须用点数图完成。
