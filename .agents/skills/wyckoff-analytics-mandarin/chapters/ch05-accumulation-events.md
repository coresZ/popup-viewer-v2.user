# Chapter 5: 吸筹中的量价行为与事件标注

## Core Idea
吸筹区间里有一组**可命名的事件**，它们串起来就是主力从"接恐慌盘"到"准备拉升"的全过程。学会按顺序识别它们，就能在拉升前而不是拉升后进场。

## Frameworks Introduced
- **吸筹事件序列**：PS → SC → AR → ST →（Spring / Shakeout）→ Test → SOS → LPS → BU。用法：把区间内的每一根关键量价当作序列中的一个位置来判断"现在走到哪一步"。
- **区间边界的确定法**：**SC 的最低点 + 成功的 ST 点 + AR 的最高点**共同决定横盘振荡市场的范围；在上下边界画水平线，用来观察后续行为。用法：先画框，再读框内行为。
- **Spring 的真伪判据**：价格跌破支撑区时——**卖盘不大（成交量小）→ 表明可以上涨**；**卖盘很大 → 价格可能还要继续下跌**；**不大不小 → 还要继续测试支撑，此时要谨慎**。

## Key Concepts
- **PS 初始支撑**：长期下跌后大量买盘进场形成明显支撑；成交量放大、振幅变大 → 下跌行情可能要结束。
- **SC 卖出密集区（抛售高潮）**：振幅变大、卖压最大，大众恐慌卖盘被专业人士在底部附近吃掉；通常**收盘价远离最低价** → 说明大机构在此价位抢购。
- **AR 自动反弹**：卖压消耗殆尽后市场自动反弹；买盘轻松推高、空头回补助推；**反弹顶点帮助确认横盘振荡市场的顶部**。
- **ST 第二次测试**：价格再次跌到 SC 附近测试供需平衡；若底部确认，接近 SC 时成交量与振幅都明显减小；**多个二次测试也常见**。
- **Spring（弹簧效应）**：把价格拉到区间之下、然后又收盘在区间之内；目的是误导大众并在低价收买筹码。
- **Shakeout（震仓）**：终极震仓=收集区间尾部的"打了激素的弹簧效应"；也可发生在拉升后（股价迅速下跌恐吓散户卖筹）。洗盘让筹码从意志不坚定者手中转移到主力手中；**洗盘不是拉升的必须阶段**（原文图二有洗盘、图三没有）。
- **Test（测试）**：上涨过程中在交易区间与重要价格区测试供应量；发现大量供应 → 市场还没做好拉升准备；Spring 后常有一个或多个测试，**底部越来越高、成交量减小 → 价格可能很快拉升**。
- **SOS 强势信号**：价格上涨的同时放量，且振幅变大；常出现在洗盘之后，分析师以此**确认之前对市场的解读**。
- **LPS 最后支撑点**：回调在支撑点结束；SOS 之后价格**缩量**回调到支撑点且**振幅变小**；有些走势中回调不止一次。
- **BU（back-up，回调）**：术语由罗伯特·伊万斯（1930–1960 年代威科夫分析法大师）提出。把 SOS 比喻成"跳过股价压力区"，回调意味着股价又回到压力区 → 表示有投资者短线获利了结，同时该位置卖盘需要测试。形式多样：可能是简单价格回调，也可能在高位形成新的调整区间。

## Mental Models
- **"先画框再读框内"**：没有 SC/AR/ST 定出的区间边界，任何 Spring 判断都是空谈。
- **量缩的下跌是"好消息"**：接近 SC 或跌破支撑时成交量萎缩，说明供应在枯竭。
- **SOS 是确认、不是起点**：它是"之前的解读被验证"，追高买入不如等 LPS。
- **洗盘可选，测试必需**：不要把"必须有 Spring"当铁律。

## Anti-patterns
- **把任意假突破都叫 Spring**：没有"收回区间内"且成交量不支持，就不是。
- **忽略 AR 顶点的作用**：它是区间上沿的一半依据，漏掉会画错框。
- **在 SOS 处追高**：原文的入场点在 LPS（缩量回调、振幅变小）。
- **假设洗盘必然出现**：原文明确指出它不是拉升的必须阶段。

## Worked Example
一次典型的吸筹读图顺序（原文口径）：
1. 长期下跌末端出现 **PS**：大量买盘进场、量增幅增 → 下跌可能结束。
2. 出现 **SC**：振幅最大、恐慌抛售被专业资金接走，收盘远离最低价。
3. **AR**：卖压耗尽后自动反弹，其顶点与 SC 最低点一起框出区间。
4. **ST**：再次回到 SC 价位附近，成交量与振幅明显减小 → 底部确认（也可能出现多次）。
5. **Spring/Shakeout**：跌破支撑又收回区间内；**关键看跌破时的成交量**——量小则可涨、量大则可能继续跌、不大不小则继续观察。
6. **Test**：Spring 之后的一次或多次回测，底部抬高、量能递减。
7. **SOS**：放量上涨、振幅放大，确认前面的解读。
8. **LPS**：缩量、小振幅回调到支撑点 → 进场点。
9. **BU**：越过压力区后的回抽，可能是简单回调，也可能在高位形成新调整区间。

## Key Takeaways
1. 吸筹是一串**有序事件**，不是单一形态。
2. 区间边界由 **SC 最低点 + 成功 ST + AR 最高点**确定。
3. Spring 的判据是**跌破时的成交量**（小=可涨）。
4. **SOS 确认解读，LPS 提供入场**。
5. 洗盘可有可无；**测试才是必需的**。
6. 量价特征：下跌趋近底部时"量缩幅减"，上涨确认时"量增幅增"。
