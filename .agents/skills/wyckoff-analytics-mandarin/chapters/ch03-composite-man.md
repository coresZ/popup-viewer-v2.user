# Chapter 3: 综合人（Composite Man，市场主力）

## Core Idea
把市场里所有股票、所有波动都当作**同一个人**有计划地操作出来的结果——这个人就是"综合人"。交易者的任务不是猜消息真假，而是通过图谱判断综合人正在做什么、下一步想做什么。

## Frameworks Introduced
- **综合人（composite man）**：威科夫对市场主力的拟人化模型。用法：遇到任何量价现象，先问"如果这是一个人干的，他为什么这么做？"
- **操纵三阶段叙事**：计划 → 执行 → 完成。用法：把吸筹（建仓）、拉升（markup）、派发（出货）、下跌（markdown）看成同一个人的连续动作，而不是孤立行情。
- **诱多机制（吸筹后的高量拉升）**：综合人在积累大量筹码后，通过**高成交量**吸引散户进场买入；大量买卖使成交量显著放大，向散户"显示"这只股票前景广阔。用法：把"突然放量上涨"同时视为可能的**派发窗口**，而非无条件利好。

## Key Concepts
- **综合人（composite man）**：市场主力的集合体，被当作单一操盘者。
- **行情的真假不重要**：威科夫明确表示真假不重要，重要的是**行为与动机**。
- **图谱（tape/chart）**：判断行为与动机的唯一客观依据。
- **动机（motive）**：隐藏在量价背后的目的，需通过学习和练习才能洞察。

## Mental Models
- **"把行情当人看"**：任何放量、缩量、假突破，都先假设是某个人为了某个目的做出来的。
- **反向提问**：当走势"看起来"要涨时，问"这对我有利，还是对综合人有利？"
- **筹码转移视角**：吸筹与派发本质是筹码在主力与散户之间的转移，成交量是转移的痕迹。

## Anti-patterns
- **只研究消息**：威科夫明确说"行情真假都不重要"，纠缠消息面会错过图谱证据。
- **把放量上涨一律当利好**：这恰恰是综合人吸引散户接盘的手段之一。
- **把综合人当阴谋论**：它是**分析工具**（"假设是同一人操作"），不是需要证实的实体。

## Worked Example
原文的推理链：综合人认真地计划、执行并完成自己的股票操纵过程 → 在积累大量筹码后，通过高成交量吸引散户进场 → 大量买入与卖出使成交量显著放大，让散户觉得前景广阔 → 因此交易者必须研究图谱，判断股票行为与综合人的动机 → 通过学习和练习，交易者能洞察图谱背后隐藏的动机 → 越早看懂综合人的意图，就越早发现交易与投资机会并从中获利。

## Key Takeaways
1. 综合人是**分析假设**，用来统一解释量价现象。
2. 行情的真假不重要，**行为与动机**才重要。
3. 高量上涨可能是吸引散户的手段，必须结合所处阶段判断。
4. 判断依据只有图谱（K 线图、点数图、成交量、时间）。
5. 洞察动机需要大量练习，属于技能而非知识。
