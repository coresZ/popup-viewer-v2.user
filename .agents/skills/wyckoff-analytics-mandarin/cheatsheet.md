# Cheatsheet — 威科夫方法决策速查

> 一页纸的判断规则。来源：《Wyckoff-Method_WyckoffAnalytics-mandarin》（Wyckoff Analytics）。

## 决策规则（When X → Do Y, because Z）

| 观察到的现象 | 该做什么 | 为什么 |
|---|---|---|
| 长期下跌后量增、振幅变大（PS） | 停止做空，开始观察 | 大量买盘进场形成支撑，下跌可能结束 (Ch5) |
| 恐慌抛售后收盘远离最低价（SC） | 等 AR 与 ST 确认，不追 | 专业资金在底部接货，区间下沿正在形成 (Ch5) |
| 回到 SC 附近但量减、幅缩（成功 ST） | 区间确认，准备等 C 阶段测试 | 供应在枯竭，底部被确认 (Ch5) |
| 跌破支撑后**量小**并收回区间（Spring） | 初步建仓 | 卖盘衰竭，主力洗盘后准备拉升 (Ch5, Ch6) |
| 跌破支撑后**量大** | 继续观察，可能还要跌 | 卖盘真实，供应仍大 (Ch5) |
| 跌破支撑后量不大不小 | 谨慎，继续等测试 | 还需再次测试支撑区 (Ch5) |
| Spring 后多次测试且底部抬高、量递减 | 加仓窗口 | 拉升前的典型准备 (Ch5) |
| 放量上涨 + 振幅放大（SOS） | 确认解读，**等 LPS 再进** | SOS 是确认信号，不是最佳入场点 (Ch5, Ch6) |
| SOS 后缩量、小振幅回调（LPS） | 买入 / 加仓 | 需求大于供应，风险回报最佳 (Ch6) |
| 连续放量但涨幅越来越小 | 警惕出货，准备离场 | 量价不协调原理：庄家正在出货 (Ch4) |
| 大幅上升后量增、振幅加宽（PSY） | 停止做多 | 主力开始大量派发 (Ch7) |
| 利好消息中出现巨量长阳（BC） | 视为派发窗口，不追多 | 公众买单被主力卖单满足 (Ch7) |
| 突破区间上沿后迅速收回（UTAD） | 激进者可试空，稳妥者等 D | 对剩余需求的测试，庄家会反复清洗做空者 (Ch7, Ch8) |
| 价格跌到区间底部、量价齐增（SOW） | 性质已变，转空思路 | 供应开始主导市场 (Ch7) |
| 虚弱上升、价差变窄（LPSY） | 做空 / 加空 | 需求枯竭，快速下跌前的最后一波派发 (Ch7, Ch8) |
| 下跌趋势中价格回到跌破的支撑线附近 | 高胜算做空点 | 回踩确认跌破有效性 (Ch8) |
| 阶段 D 仍在做多 | 立即纠正 | 原文：任何在阶段 D 仍做多的人都是自找麻烦 (Ch8) |

## 事件镜像对照表

> 时间顺序按阶段归属：吸筹侧 `PS → SC → AR → ST →（Spring/Shakeout）→ Test → SOS → LPS → BU`；派发侧 `PSY → BC → AR → ST → SOW →（UTAD）→ LPSY`（SOW=B、UTAD=C、LPSY=D）。

| 吸筹侧 | 派发侧 | 含义 |
|---|---|---|
| PS 初始支撑 | PSY 初始供应 | 趋势可能结束 / 可能反转 |
| SC 抛售高潮 | BC 购买高潮 | 极端情绪与巨量 |
| AR 自动反弹（顶点定上沿） | AR 自然回落（低点定下缘） | 界定区间边界 |
| ST 二次测试（量缩幅减） | ST 二次测试（量缩幅缩） | 确认底部 / 顶端 |
| Spring / Shakeout（向下假突破） | UTAD（向上假突破） | 洗盘与陷阱 |
| Test（底部抬高、量递减） | 需求测试（上冲回落） | 拉升 / 下跌前的检验 |
| SOS 强势信号 | SOW 弱势信号 | 性质改变的确认 |
| LPS 最后支撑点 | LPSY 最后供应点 | 入场 / 出场机会 |
| BU 回调 | — | 越过压力区后的回抽 |

## 阶段 → 动作

| 阶段 | 吸筹（做多视角） | 派发（做空视角） |
|---|---|---|
| A | 观察，等 SC/AR/ST 框定区间 | 观察，等 PSY/BC/AR/ST |
| B | 跟踪下行波段量能是否递减 | 跟踪供需是否向供应倾斜 |
| C | **低量 Spring / 震仓处初步建仓** | 等上冲回落 / UTAD；激进者可试空 |
| D | **LPS 买入 / 加仓** | **LPSY 做空 / 加空** |
| E | 持有；注意脚踏石与新高 | 回踩跌破位做空；止损随趋势下移 |

## 快速识别信号（Tells）

- **量缩的下跌** → 供应在枯竭，别急着看空 (Ch5, Ch6)
- **量增但价滞（或跌幅收窄）** → 有大买家在吸收供应 (Ch9)
- **放量长阳出现在利好里** → 大概率是派发窗口 (Ch7)
- **涨势"脆弱无力"** → 熊市中的反弹，不是新趋势 (Ch8)
- **回调短促、不明显** → 阶段 E 特征，趋势健康 (Ch6)
- **区间内出现更窄的新区间** → 脚踏石，目标可确认 (Ch11)

## 最高胜率组合信号

| 方向 | 组合链路 | 关键点 |
|---|---|---|
| **做多** | 低量 Spring（C）→ Test 底部抬高、量递减 → **SOS 确认** → **LPS 入场** | SOS 只确认，入场在 LPS |
| **做空** | UTAD（C）→ 跌破支撑/跌下区间中线 → **LPSY 做空** | 不要在 UTAD 直接做空（庄家反复清洗） |

## 三条红线

1. **永不要只看点数图一个阶段所预测的结果** (Ch11)。
2. **点数图的"阶段"≠ 吸筹/派发的阶段 A–E**，两套划分不可混用 (Ch11)。
3. **洗盘不是拉升的必须阶段**，UTAD 也不是派发的必要因素——缺了不代表判断错误 (Ch5, Ch7)。
