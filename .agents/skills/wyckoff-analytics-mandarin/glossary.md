# Glossary — 威科夫方法术语表

> 术语来源：《Wyckoff-Method_WyckoffAnalytics-mandarin》（Wyckoff Analytics，14 页图解手册）。括号内为所属章节。

## 英文缩写事件（按字母序）

- **AR（Automatic Rally / 自动反弹）** — 卖压消耗殆尽后市场自动反弹；其顶点帮助确认吸筹区间上沿 (Ch5)
- **AR（Automatic Reaction / 自然回落）** — 派发中 BC 之后买盘急剧下降但卖盘高量供应持续；其低点界定派发区间下缘 (Ch7)
- **BC（Buying Climax / 购买高潮）** — 成交量与振幅显著增大、购买力达到高潮；常在利好中出现，机构借机出货给散户 (Ch7)
- **BU（Back-Up / 回调）** — 伊万斯提出的术语；SOS 越过压力区后的回抽，表示短线获利了结与卖盘需测试 (Ch5)
- **LPS（Last Point of Support / 最后支撑点）** — SOS 后缩量、小振幅回调到支撑点；买入或加仓机会，也是点数图计数起点 (Ch5, Ch11)
- **LPSY（Last Point of Supply / 最后供应点）** — 需求枯竭的标志，大机构在快速下跌前的最后一波派发；做空或加空机会 (Ch7)
- **PS（Preliminary Support / 初始支撑）** — 长期下跌后大量买盘进场形成明显支撑；量增、振幅变大，下跌可能结束 (Ch5)
- **PSY（Preliminary Supply / 初始供应）** — 价格大幅上升后主力开始大量派发的位置；量增、振幅加宽 (Ch7)
- **SC（Selling Climax / 卖出密集区、抛售高潮）** — 振幅最大、卖压最大，恐慌卖盘被专业资金在底部吃掉；收盘常远离最低价 (Ch5)
- **SOS（Sign of Strength / 强势信号）** — 上涨同时放量且振幅变大；常出现在洗盘后，用于确认此前解读 (Ch5)
- **SOW（Sign of Weakness / 熊市初显、弱势信号）** — 价格跌到区间底部甚至稍突破，常伴随价差与成交量增大；与 AR 一起表示供应开始主导 (Ch7)
- **ST（Secondary Test / 二次测试）** — 价格回到 SC（或 BC）附近测试供需平衡；底部/顶端确认时成交量与振幅显著减小 (Ch5, Ch7)
- **UTAD（Upthrust After Distribution / 派发后上冲回落）** — 向上洗盘，与 Spring 相反；突破区间后对剩余需求做决定性测试，是"牛市"陷阱 (Ch7)

## 核心概念

- **综合人（Composite Man）** — 把市场所有股票与波动视为同一个人操作的结果；分析假设而非实体 (Ch3)
- **威科夫五步法** — 判势 → 选股 → 因果目标 → 九检验 → 应变 (Ch2)
- **三大定律** — 供需原理（方向）、因果原理（幅度）、量价不协调原理（转折预警）(Ch4)
- **供需原理** — 供小于求则涨、供大于求则跌；通过价格与成交量的关系分析 (Ch4)
- **因果原理** — 区间内水平点数图计数为"因"，突破后价格运动为"果" (Ch4, Ch11)
- **量价不协调** — 成交量与价格不协调常是趋势改变信号（如连续放量但涨幅越来越小）(Ch4)
- **努力与结果（Effort vs Result）** — 成交量=努力，价格变动=结果；协调/减弱/背离各有含义 (Ch9)
- **比较强度 / 相对强度比** — 比较个股与大市或指数在同点位的强弱，可消除衡量口径差异 (Ch9)
- **交易区间（Trading Range）** — 横盘整理区间，因果计数与吸筹/派发判断的舞台 (Ch4)
- **吸筹（Accumulation）** — 主力在低位收集筹码的过程，含阶段 A–E (Ch5, Ch6)
- **派发（Distribution）** — 主力在高位把筹码交给公众的过程，含阶段 A–E (Ch7, Ch8)
- **再吸筹 / 再派发** — 趋势中继处的同构区间；时间更短、幅度更小 (Ch6, Ch8)
- **Spring（弹簧效应）** — 价格拉到区间之下又收回区间内；目的是误导大众并在低价收买筹码 (Ch5)
- **Shakeout / 终极震仓** — 收集区间尾部的"打了激素的弹簧效应"；也可发生在拉升后 (Ch5)
- **Test（测试）** — 在区间与重要价格区测试供应量；底部抬高、量能递减预示即将拉升 (Ch5)
- **洗盘** — 跌破支撑再返回，属空头陷阱；**不是拉升的必须阶段** (Ch5, Ch6)
- **浮筹** — 意志不坚定的持仓；被主力吸纳时表现为下行波段量能递减 (Ch6)
- **空头陷阱** — 跌破支撑后快速收回，终结下跌趋势并套住最后卖家 (Ch6)
- **脚踏石盘整（Stepping Stone）** — 趋势中继的窄区间，可确认点数图目标并推断突破时点 (Ch6, Ch11)
- **markup / markdown** — 上升段 / 下跌段 (Ch4)
- **点数图（P&F）** — 用于因果计量的图种；图框尺寸与反转值是关键参数 (Ch11)
- **图框尺寸（Box Size）** — 点数图每格的价格幅度：低价股 0.5–1 点、高价股（>200 美元）5 点、道指 100 点 (Ch11)
- **反转值（Reversal）** — 点数图转向所需的格数（示例用 3 点反转）(Ch11)
- **九个买入检验 / 九个卖出检验** — 交易区间结束、新趋势启动的九条核对条件，含图谱分工与 3 倍止损规则 (Ch10)
- **最小阻力方向** — 九检验所描绘的、趋势即将选择的方向 (Ch10)
- **下跌目标 / 上涨目标** — 由点数图计数给出的目标价位（最低值/均值/最高值构成目标带）(Ch10, Ch11)
- **"停，看，听"** — 到达点数图目标价后的观察纪律：目标是可能反转的位置，不是精确终点 (Ch11)
- **底部铸成 / 冠状顶部铸成** — 买入侧的水平底部与卖出侧的横向顶部结构确认 (Ch10)
- **3 倍止损规则** — 目标盈利至少为初始止损距离的 3 倍（检验 9）(Ch10)
- **股票市场学院（Stock Market Institute）** — 威科夫 1930 年建立、教授识别吸筹与派发的学校 (Ch1)
- **鲍勃·伊万斯（Bob Evans）** — 威科夫去世后发展并推广其课程的学生；BU 术语的提出者 (Ch1, Ch5)
