## Core Frameworks & Mental Models

### 总纲：五步法（Ch2）
自上而下漏斗，顺序不可颠倒：
1. **判势** — 用主要指数的 K 线图 + 点数图确定市场现状与可能趋势，决定是否入场、做多还是做空。
2. **选股** — 上涨趋势选**强于**市场的股票；下跌趋势选**弱于**市场的股票。
3. **定空间** — 用点数图确认"原因"≥ 最低目标（因果律：区间水平计数=因，突破后价格运动=果）。
4. **定时机** — 应用九个买入/卖出检验。
5. **定风险** — 约 **3/4** 股票随大盘，故以指数反转作为应变信号；下止损单并跟随交易。

### 三大定律（Ch4）
- **供需原理 → 决定方向**：供小于求涨、供大于求跌；通过价格与成交量的关系分析，需长期练习。
- **因果原理 → 决定幅度**：横盘区间的点数图水平计数=因，突破后的价格运动=果。
- **量价不协调 → 提前预警转折**：典型是"连续放量但涨幅越来越小 → 庄家正在出货"。

### 综合人（Ch3）
把市场所有股票与波动当作**同一个人**有计划操作的结果。行情真假不重要，**行为与动机**才重要；主力在积累大量筹码后会**用高成交量吸引散户进场**，所以"突然放量上涨"要同时当作可能的派发窗口。

### 努力与结果（Ch9）
成交量=努力，价格=结果。三种组合：
- 价差增大 + 量增 + 下跌 → **协调**（供应真实）
- 价差变小 + 量减 → **供应减低**（可能短暂上扬）
- 跌幅减少 + **量增** → **大买家吸收供应**（预计继续上涨）

**比较强度**：用**相对强度比**在相同点位比较个股与大市，可消除衡量口径差异（九检验第 7 条）。

### 吸筹：事件序列（Ch5）
`PS → SC → AR → ST →（Spring / Shakeout）→ Test → SOS → LPS → BU`
- **区间框定**：**SC 最低点 + 成功的 ST + AR 最高点**决定横盘振荡范围，先画框再读框内。
- **Spring 真伪只看跌破时的成交量**：量小 → 可涨；量大 → 可能继续跌；不大不小 → 继续测试，需谨慎。
- **SOS 是确认，不是入场**；入场在 **LPS**（缩量、小振幅回调）。
- 洗盘**不是**拉升的必须阶段。

### 吸筹：阶段 A–E（Ch6）
A 止跌（PS/SC/AR/ST）→ B 建仓（**下行波段量能递减**）→ C 测试（**低量 Spring/震仓 = 初步建仓**）→ D 需求主导（**LPS 买入/加仓**）→ E 离开区间（脚踏石，预示新高）。
再吸筹：看不到主要 PS/SC/ST，A 形似派发 A，B–E 同构但**时间更短、幅度更小**。

### 派发：事件序列（Ch7）
`PSY → BC → AR → ST → SOW →（UTAD）→ LPSY`（按阶段归属排序：SOW 属 B、UTAD 属 C、LPSY 属 D；源文档清单顺序不同，勿当时间顺序）
- 与吸筹完全镜像：BC↔SC、UTAD↔Spring、SOW↔SOS、LPSY↔LPS。
- **BC 经常在利好消息中出现**——机构借机出货给散户。
- **AR 低点界定区间下缘**；**BC/其他 ST 构成阻力区**。
- **SOW 表示供应开始主导**；**LPSY = 需求枯竭**，快速下跌前最后一波派发。

### 派发：阶段 A–E（Ch8）
A 停涨（PSY/BC 首次预示供应进入）→ B 清仓建空 → C 测试需求（上冲回落/UTAD）→ D 供应主导（**LPSY 做空/加空**）→ E 下跌展开（**回踩跌破的支撑线 = 高胜算做空点**）。
判据：**需求无法再回到前高**即进入 D。原文纪律：*任何在阶段 D 仍然做多的人都是自找麻烦*。

### 九个买卖检验（Ch10）
买入侧：① 价格已达下跌目标（点数图）② PS+SC+ST ③ 看涨行为（涨量增、跌量减）④ 下行步调被打破 ⑤ 底抬高 ⑥ 顶抬高 ⑦ 强于大市 ⑧ 底部铸成 ⑨ **目标 ≥ 初始止损的 3 倍**。
卖出侧完全镜像（上涨目标 / PSY+BC / 看跌行为 / 上行步调破 / 顶降低 / 底降低 / 弱于大市 / 冠状顶部铸成 / 3 倍止损）。
**图谱分工**：检验 1、9 必须用点数图；7 用相对强度；其余用 K 线图与/或点数图。

### 点数图因果计数（Ch11）
① K 线图与点数图研究同一段区间与时间 ② 选图框尺寸：低价股 **0.5–1 点**、高价股（>200 美元）**5 点**、道指 **100 点** ③ 区间右侧确认 SOS 后找 **LPS** ④ **从 LPS 向左计数**，先保守再按阶段扩展，一次一个阶段 ⑤ 至少给两个目标（区间最低值、计数列与最低值的**均值**）⑥ 目标价 = **列数 × 图框尺寸 × 反转值**，加到「计数列 LPS 横向值（最高）/ 区间最低值（最低）/ 两者均值」。
红线：**永不要只看一个阶段的结果**；点数图的"阶段"**不等于**吸筹/派发阶段 A–E。到价后"**停，看，听**"——目标是可能反转的位置，不是精确终点。

### 最高胜率组合与纪律
- **做多组合**：低量 Spring（阶段 C）→ Test 底部抬高、量能递减 → **SOS 确认** → **LPS 入场**。
- **做空组合**：UTAD（阶段 C）→ 跌破支撑或跌下区间中线 → **LPSY 做空**（源文：比在 UTAD 处直接做空更安全，因为庄家会反复用上冲回落清洗做空者）。
- **两条纪律**：SOS 是**确认**不是入场，LPS 才是入场；UTAD 是**测试**不是出场，LPSY 才是出场。
